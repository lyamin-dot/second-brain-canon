# second-brain-canon

Карта репозитория. Правила — в Skill `second-brain-git`, не здесь.

## Структура

```
core/         канон системы по нумерованным разделам (R-NN.md)
meta/         протоколы и контракты, действующие для любого проекта
registry/     реестры: адреса проектов, ID инструментов
projects/     папки проектов, по одной на проект
```

## Четыре роли файла проекта

Внутри `projects/<имя>/`:

| Файл | Что в нём |
|---|---|
| `STATE.md` | где проект сейчас |
| `PLAN.md` | правила и замысел этого проекта |
| `LOG.md` | что случилось: решения, тупики, ошибки |
| `NOT_TAKEN.md` | что не взяли при переносе из Docs и адрес восстановления |

## Адреса

Состав проектов и их папки — в [`registry/projects.md`](registry/projects.md).
