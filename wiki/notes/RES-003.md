# RES-003 — устройство базы знаний для агентов без памяти между сессиями

Источник: отчёт Perplexity «LLM Agent Knowledge Base Design», Google Doc 1zgNf6Mpau2onILsv_0pXl3y-67jQC12C5u6NhtiOMDw, разделы 1–10. Разобран 2026-09-25, решение — Р-30 журнала projects/kontext-reduktion/LOG.md. Пересмотр: 2026-12-25 или при смене модели.

Первоисточники отчёта этой сессией не открывались, поэтому буква почти везде C — пересказ. Собственные пометки отчёта «measured» и «documented» кодом доверия не считаются: например, «сокращение на 60 процентов» взято из одного обсуждения на GitHub. Признаки небрежной сборки: остатки разметки внутри текста, модель Claude 3.5 Haiku как рекомендуемая — значит, источники старше текущих моделей.
