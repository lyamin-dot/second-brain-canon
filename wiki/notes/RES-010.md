# RES-010 — как Андрей будет видеть данные из базы mkt2 (исследование И-4 проекта marketplace-rebuild)

Пакет Б контракта автопилота 2026-10-31 (projects/marketplace-rebuild/PLAN.md, раздел 16; записи Р-39, Р-40 журнала projects/marketplace-rebuild/LOG.md). Источники — первоисточники в интернете (прочитаны 2026-10-31 субагентом-исследователем, адреса при утверждениях) и база mkt2, читанная только воркфлоу «MKT2 SQL Read» XP6mOTq6EJ3Mjxav. Читатель — подробный план справочника и пункт «Свод для Андрея в книгах» projects/marketplace-rebuild/DATA_MODEL.md. Коды доверия — wiki/DESIGN.md, пункт 2.

## Ответ

Андрей видит базу листами в своих книгах Google Sheets: воркфлоу n8n ночью, после сборщиков, выполняет запрос ролью только для чтения и перезаписывает сводный лист в книге MKT2 целиком. Деньги — 0 (n8n, PostgreSQL и Google уже работают); работа — один воркфлоу MKT2 на сводку; предел — обновление раз в сутки, лист только для чтения (ручные правки затрёт перезапись). Разовые вопросы, для которых листа нет, — агент в чате через «MKT2 SQL Read»: путь уже работает.

## Утверждения

1. Предел книги Google Sheets — до 20 млн ячеек или 100 МБ. — A2, support.google.com/drive/answer/37603.
2. Connected Sheets подключается только к BigQuery; PostgreSQL не упомянут. — A2, support.google.com/docs/answer/9702507.
3. JDBC Apps Script поддерживает PostgreSQL, но для базы вне Cloud SQL нужно открыть порт диапазонам адресов Google (goog.json), порт не ниже 1025. — A2, developers.google.com/apps-script/guides/jdbc.
4. Коннектор Looker Studio к PostgreSQL: доступ диапазону 142.251.74.0/23, до 150 тысяч строк на запрос, без особого запроса видна только схема public (наши схемы — raw и ref). — A2, docs.cloud.google.com/data-studio/connect-to-postgresql.
5. Metabase: открытая версия бесплатна (AGPL), облако от 100 долларов в месяц; для работы нужна своя служебная база вместо встроенной H2. — A2, metabase.com/pricing, metabase.com/license, metabase.com/docs/latest/installation-and-operation/running-metabase-on-docker.
6. Grafana переходит с Apache 2.0 на AGPLv3; Apache Superset — Apache-2.0. — A2, grafana.com/licensing, github.com/apache/superset.
7. На сервере 7,7 ГБ памяти без подкачки; там n8n, PostgreSQL, OCR, Vaultwarden, Caddy. — B2, projects/archive-recon/SERVER_TASKS.en.md, строки 18 и 45 (замер 2026-10-13).
8. «MKT2 SQL Read» отвечает за 10–35 мс; вход — текст SQL, выход — строки; не опубликован, работает из MCP в режиме manual. — A1, исполнения 90507–90513, 90720.

## Проба (исполнение 90513, 2026-10-31; перечитано диспетчером)

Недельная сводка по кабинетам ИП из сырых строк (текущая версия строки — наибольший last_loaded_at по ключу): WB — raw.wb_finance_row, Ozon — raw.ozon_accrual. 13 строк, 6 колонок: кабинет, неделя, штук, покупатель заплатил, к выплате, строк-источников. Пример: ip_ozon, неделя с 19.10.2026 — 47 штук, 108 096 ₽, к выплате 51 748 ₽; ip_wb та же неделя — 3 штуки, 4 367 ₽, 3 313 ₽. Недели января–февраля 2026 у ip_wb — продаж 0, только удержания.

Гипотеза (не проверена): колонка «к выплате» (WB: forPay минус логистика, штрафы, хранение, удержания, приёмка; Ozon: сумма total_amount всех начислений) совпадает с итогом недельного отчёта WB и с выплатой в кабинете Ozon. Проверить до построения листа: отчёт о реализации WB ИП и раздел «Финансы» Ozon ИП за неделю с 19.10.2026 против строк исполнения 90513.

## Отвергнуто

- (б) — новая постоянно работающая программа с входом из интернета, служебной базой и памятью на нагруженном сервере; даёт то же, что лист в книге, в незнакомом месте.
- (г) — порт базы пришлось бы открыть широким диапазонам адресов Google; Connected Sheets PostgreSQL не умеет (2). Гипотеза (не проверена): порт PostgreSQL сейчас наружу не опубликован; проверить по docker-compose сервера.
- (в) как единственный путь — регулярный просмотр требует готового листа, а не вопроса каждый раз; как дополнение остаётся.
