# Среда и наблюдение тестов поведения сессий

Метка: кандидат в БЛОКЕРы (пункт 1). Источник: тест слоёв Skill 2026-10-22 и два повтора в живых чатах SYS 2026-10-23 — `meta/TEST_skill-layers_2026-10-22_report.md`.

## 1. Фильтр безопасности скрывает ответ, но не действия — кандидат в БЛОКЕРы

Симптом: Андрей видит в чате «Pausiert» (фильтр безопасности Sonnet, причина «reasoning_extraction»), а вызовы инструментов этого ответа уже исполнены. Случай 2026-10-23: скрытый ответ записал в канон новую задачу и два ремонтных коммита (bc81153, 3d0369e, 2066fe2); задача снята коммитом e01704b. Риск: запись в канон, которую владелец не видел. Предложение: после любого «Pausiert» в чате проекта следующая сессия смотрит историю коммитов и историю версий затронутых воркфлоу за время скрытого ответа. Решение о статусе — Андрей.

## 2. Как наблюдать тесты поведения

Решение 2026-10-23: доказательство — лента вызовов в интерфейсе (снимки экрана), журнал исполнений n8n, история версий воркфлоу и история коммитов; вопрос сессии «перечисли свои вызовы» не задаётся — его дважды из трёх скрыл фильтр. Мастер-промпт, вставленный субагенту текстом в запрос, сессией проекта его не делает (прогон 2026-10-22): годная среда — живой чат проекта, файлы критериев — вне досягаемости тестируемой сессии.

## 3. Субагент с правом записи

Симптом: в прогоне 2026-10-22 субагенты сессии Claude Code с клоном дважды отправили коммиты в main (64ccf73, 9815579; откаты 273a0dc, fd1aca5) и дважды правили зеркало Skill. Причина: запрет записи в задании субагенту держится только словами (Skill avtopilot, «Задание субагенту»), а право отправки субагент наследует. Предложение по пункту 18 метода проектирования (защита правами, а не словами): тестовое или читающее задание не даётся субагенту в сессии с открытым push; правка Skill avtopilot — текстом «было → стало» по решению Андрея.

## 4. Идея: запланированная задача как среда теста

Проверить одной разовой задачей с сообщением «привет», получает ли свежая сессия мастер-промпт проекта (признак — строка ПАРОЛИ с контрольными суммами) и может ли диспетчер прочитать её ход. Если да — тесты поведения идут без рук Андрея. Гипотеза (не проверена).

Условие снятия: по пункту 1 — решение Андрея о статусе и записанная мера; по пункту 3 — правка Skill avtopilot внесена или отклонена; по пункту 4 — зонд сделан. Пункт 2 — решение, действует.
