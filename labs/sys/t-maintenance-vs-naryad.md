# Обслуживание идёт мимо ролевого протокола

Суть: CORE Р.12 п.10 (ПРОТОКОЛ v3) распределяет работу по чатам и моделям, тогда как `naryad` §3.1 распределяет её по средам, ролям, мандатам и идентификаторам. Пункт дублирует Skill и одновременно сужает его. Обслуживание остаётся единственной процедурой своего размера, живущей вне ролевого протокола, — то есть без мандата на отказ, без паспорта стоимости и без приёмки по объекту.

Следующий шаг: разбирать вместе с противоречием п.3/п.10 (`t-p12-conflict.md`) — оба про один и тот же пункт и после снятия заморозки Р.12.

Условие снятия (дословно из источника): «Готово = п.10 удалён либо явно подчинён §3.1, решение внесено в CHANGELOG».
