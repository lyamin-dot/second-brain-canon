# Разделитель колонок в литерале массива формулы: Apps Script против Sheets API

Метка: РУТИНА. Заведена 2026-10-18 сессией SYS по решению В15 харвеста 2026-10-18 (файл meta/HARVEST_2026-10-18_answers.md).

## Суть

Skill apps-script-sheets (SKILL.md, раздел о локали формул) говорит: в книге с локалью ru_RU разделитель колонок в литерале массива — обратная косая черта. Случай 2026-10-09: формула с таким литералом, записанная через Sheets API с USER_ENTERED (воркфлоу gsheets-append), дала #ERROR! в 14 колонках (meta/PRODUCT_DATA_HIERARCHY.md, строка про XLOOKUP; запись Р-11 пункт 4 журнала projects/deklaration-wb/LOG.md). Возможно, решает путь записи, а Skill пути не различает.

## Следующий шаг

Проба в новой пустой книге, без записи в рабочие книги: одна и та же формула с литералом массива записывается двумя путями — setFormula из Apps Script и values.update с USER_ENTERED через Sheets API; читается результат.

## Условие снятия

Результат пробы записан; если пути различаются — правка Skill apps-script-sheets текстом «было → стало» позицией очереди.
