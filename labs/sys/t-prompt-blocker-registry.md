# Мастер-промпт SYS ищет блокеры в файле, где их нет

Метка: РУТИНА. Заведена 2026-10-11 сессией SYS (Аргус) на !save; захват из разбора замороженного SYS_INDEX проектом Архивариус (запись Р-22 журнала `projects/archivarius/LOG.md`, абзац «Факт для лаборатории SYS»).

## Суть

Мастер-промпт проекта SYS, раздел «Проактивная модернизация», ветка «БЛОКЕР», определяет блокер как «существующая строка в CORE Р.5 или в разделе БЛОКЕРы активного INDEX». Но файл `core/R-05.md` (это и есть CORE Р.5) держит только формулу приоритета и четыре метки — строк-задач в нём нет; проверено чтением файла 2026-10-11. Skill naryad (`references/issuer.md`, строка 23) уже называет такую ссылку ошибкой и перечисляет действующие места: `labs/sys/INDEX.md`, файлы STATE.md проектов в репозитории, Зона А INDEX Docs-проектов. Последствие: сессия, которая проверяет находку по промпту, ищет блокер в пустом месте и либо не находит законный блокер, либо начинает считать блокером что угодно со словом «блокер» в другом документе. Потери данных нет; правило о находках вне задачи работает хуже, чем задумано.

Копия промпта — `meta/prompts/sys.md`, строка 112; живой экземпляр — поле Project instructions проекта SYS в интерфейсе Claude, его правит только Андрей.

## Предложение — текст «было → стало»

Было:
- **БЛОКЕР** — уже зафиксированный объект: существующая строка в CORE Р.5 или в разделе БЛОКЕРы активного INDEX. Сообщи о ней сразу, со ссылкой на эту строку — это не отвлечение, а то же дело другими словами.

Стало:
- **БЛОКЕР** — уже зафиксированный объект: существующая строка с меткой БЛОКЕР в `labs/sys/INDEX.md`, в файле STATE.md проекта в репозитории или в Зоне А INDEX Docs-проекта. Сообщи о ней сразу, со ссылкой на эту строку — это не отвлечение, а то же дело другими словами. Файл `core/R-05.md` (CORE Р.5) держит только формулу приоритета и метки, строк с блокерами в нём нет.

## Следующий шаг

Андрей заменяет строку в поле Project instructions проекта SYS; до замены сохраняет текущий текст промпта файлом (second-brain-engineer Р13). Затем сессия SYS обновляет копию `meta/prompts/sys.md` той же заменой и проверяет её обратным чтением.

## Условие снятия

Строка о БЛОКЕРЕ в копии `meta/prompts/sys.md` называет `labs/sys/INDEX.md` и файлы STATE.md, а не CORE Р.5, и Андрей подтвердил, что живой промпт изменён так же.
