# Skills и мастер-промпты — единственный экземпляр закона вне контроля версий

Метка: кандидат в БЛОКЕРы. Заведена 2026-09-26 сессией SYS по аудиту системы (Аргус); статус кандидата решается при прямом контакте с Андреем.

## Суть

После переезда CORE в репозиторий действующие правила системы (контракты чтения и записи, маршруты, запреты, регламент нарядов) живут в Skills аккаунтного слоя Anthropic: second-brain-git, second-brain-engineer, google-drive-docs, n8n-engineering-manual, naryad, project-log-description, n8n-workflow-passport и другие — по замеру сессии 2026-09-26 снимок семи системных Skills в песочнице весит около 440 КБ. Ни один Skill не лежит в репозитории; у second-brain-git источника вне аккаунта нет вовсе (подтверждено владельцем 2026-09-07, позиция J-4 очереди). Мастер-промпты проектов тоже существуют только в интерфейсе (t-prompt-backup.md). Правки вносит владелец вручную; сессия проверить их не может, отсюда костыль meta/PENDING_RULES.md. Прецедент затирания сохранением из устаревшей вкладки браузера у воркфлоу есть (SYS Canary B5jkqW0bUScxmTi7) — для Skills механизм тот же.

Класс: единичная точка отказа. Канон заметок защищён версиями и адресами восстановления; закон, по которому канон ведётся, — нет.

## Предложение сессии (решение за владельцем)

Папка skills/<имя>/ в репозитории с теми же файлами, что уходят в zip при заливке в Customize, и meta/prompts/<проект>.md для мастер-промптов. Направление потока: репозиторий → Customize, не наоборот. Одним действием закрываются J-4, t-prompt-backup.md, t-skills-snapshot.md, костыль PENDING_RULES.md, а детектор дрейфа Skills (Htrj0Kyj7eT5SEhR) получает эталон в репозитории. Отвергнуто сессией: хранить Skills в Drive (второй носитель без версий); опираться на детектор дрейфа как есть (сравнивает с Drive-копиями, у second-brain-git копии нет). Карта репозитория §3 second-brain-git при этом получает новую папку — правка Skill владельцем.

## Условие снятия

Все Skills с пометкой ОБЯЗАТЕЛЬНО и мастер-промпты активных проектов лежат в репозитории; заливка в Customize делается из репозитория; строка в second-brain-git §3 о папке skills/ внесена. Либо явный отказ владельца с обоснованием.
