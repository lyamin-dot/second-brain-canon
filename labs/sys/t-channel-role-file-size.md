# Бюджет размера файла роли при записи Каналом

Метка: РУТИНА. Заведена 2026-10-31 сессией SYS по решению Андрея на пакет харвеста 2026-10-31 («Да, все рекомендации»; находка Н-67, `meta/HARVEST_2026-10-31.md`, раздел 6).

## Суть

Бюджеты размера файлов ролей проекта (STATE.md, PLAN.md и другие — таблица second-brain-git `SKILL.md`, около строки 115) при записи не проверяются. PLAN.md проекта marketplace-rebuild за неделю дорос до 106 КБ при бюджете 10 240 Б (`projects/marketplace-rebuild/LOG.md`, Р-36; файл создан 2026-10-24). Правило текстом стоит с 2026-09-26 и не срабатывает: сессия видит только свою запись, а не итоговый размер.

## Предложение

Проверка в пишущих воркфлоу Канала (Git Write, Git Replace, Git Append, Git Append File, Git Commit Files) после сборки нового текста и до PUT: если путь — файл роли проекта (`projects/*/STATE.md`, `PLAN.md` и т. п.), а новый размер больше бюджета из таблицы ролей, — запись проходит, но ответ несёт явное предупреждение с размером и бюджетом (не отказ: отказ сломал бы срочную запись). Бюджеты — одним числом на роль в коде узла или в таблице, которую читает узел.

## Условие приёмки

Пробная запись в файл роли сверх бюджета даёт предупреждение в ответе; запись в обычный файл — без предупреждения. Правка воркфлоу Канала — пакетом с перечнем узлов и «да» Андрея (second-brain-engineer, Р10).

## Условие снятия

Проверка стоит во всех пишущих воркфлоу Канала и проверена пробой; либо Андрей решает, что бюджет проверяет сессия скриптом в среде с клоном, — тогда задача закрывается строкой инструмента в `registry/tools.md`.
