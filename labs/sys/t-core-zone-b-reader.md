# CORE называет читателем Зоны Б снятый цикл обслуживания

Метка: РУТИНА. Заведена 2026-10-11 сессией SYS (Аргус) на !save; захват из разговора об архитектуре проекта Архивариус в чате SYS того же дня.

## Суть

Пункт 0.5.4 файла `core/R-06b.md` называет читателем Зоны Б документов INDEX в Google Docs «обслуживание», то есть раздел 12 CORE. Этот раздел снят решением владельца 2026-09-07 (`core/MANIFEST.md`, раздел «Разделов нет в обеих таблицах»). Значит CORE — единственный источник истины — неверно отвечает на вопрос, кто читает Зону Б. Фактическое положение на 2026-10-11: все документы INDEX с Зонами Б заморожены; записи новее 2026-08-31 прочитал харвест (`meta/PROTOCOL_harvest.md`, строка «прочитаны после заморозки»); прошлое окно — записи старше 2026-08-31 — разбирает проект Архивариус (`projects/archivarius/PLAN.md`).

## Следующий шаг

Прочитать `core/R-06b.md` целиком, подготовить правку пункта 0.5.4 с блоком ИСТОРИЯ ДИАГНОЗА по `core/R-06a.md`, пункт 0.4.1, и выдать Андрею текст «было → стало» до внесения.

## Условие снятия

Пункт 0.5.4 в main называет действующих читателей Зоны Б (или говорит, что новых записей в Зону Б нет, потому что документы заморожены), прежний текст сохранён блоком ИСТОРИЯ ДИАГНОЗА.
