# Словарь типов захвата: в Skill семь типов, в CORE восемь

Суть: Skill second-brain-engineer, главный файл, раздел Р6 (захват), строка «Типы:» перечисляет семь типов: Задача, Идея, Вопрос, Решение (с датой), Баг (симптом | причина, если известна), Результат (что исправлено → что получилось), Событие (внешнее: тариф, API, квота, версия, поведение платформы). Файл `core/R-04.md` (раздел 4 CORE, правила захвата) перечисляет восемь: «Задача / Идея / Вопрос / Решение / Проблема / Событие / Результат / Баг». Тип «Проблема» есть только в CORE. По мастер-промпту SYS при расхождении приоритет у CORE, но тип мог быть снят из Skill намеренно — поглощён типом Баг; записи о таком решении не найдено (поиск 2026-10-12 в живом Skill и в `core/`, журналы по слову «Проблема» не просматривались).

Следующий шаг: решение Андрея — (а) вписать «Проблему» в Р6 Skill с отличием от Бага (проблема — мешает, но не дефект кода или инструмента) или (б) убрать «Проблему» из `core/R-04.md` правкой по second-brain-git 6.3. Перед решением — поиск по оглавлениям журналов `projects/*/LOG.md` словами «Проблема» и «типы захвата», не было ли решения раньше.

Условие снятия: словари в Р6 Skill и в `core/R-04.md` совпадают; правка Skill — позицией в `registry/maintenance-queue.md`, правка CORE — коммитом.
