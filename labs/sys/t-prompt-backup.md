# Мастер-промпты нигде не резервируются

Суть: тексты мастер-промптов Claude-проектов существуют в одном экземпляре — в интерфейсе Anthropic. Источник (дословно): «CORE Р.2 хранит URL, Skill — эталон, фактический текст только в UI Anthropic»; сейчас URL проектов лежат в `registry/projects.md` (перенос Р-66). Фактический текст промпта не лежит нигде: ни на Drive, ни в repo, ни в бэкапе. Промпт при этом решает, что сессия читает на старте и какому контракту подчиняется.

Следующий шаг: решение владельца — резервировать или явно отказаться. Если резервировать, носитель определяется по правилу выбора: текст, который правит только человек и читает только человек, не обязан ехать в repo.

Условие снятия (дословно из источника): «Готово = решение резервировать или явный отказ с обоснованием».

Ссылки: `registry/projects.md` (URL проектов); источник — Зона А SYS_INDEX, строка 265; дата появления в источнике не проставлена. Тот же класс, что единственный экземпляр текста Skills — позиция J-4 очереди обслуживания.
