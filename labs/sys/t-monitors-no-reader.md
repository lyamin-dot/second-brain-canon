# Мониторы и журналы, чей читатель снят вместе с циклом обслуживания

Метка: кандидат в БЛОКЕРы. Заведена 2026-09-17 по захваченной находке сессии, закрывшей этап 2 Р-66 (Р-94 журнала `projects/git-migration/LOG.md`). Статус кандидата решается при прямом контакте с Андреем.

## Суть

Регламент обслуживания (Раздел 12 CORE) снят 2026-09-07 и удалён из репозитория 2026-09-17. Он был единственным читателем у пяти объектов наблюдения: они работают и пишут, но забирать результат теперь некому. Класс тот же, что у списка «ОЖИДАЕТ АРХИВА» (Р-90) и у очереди правок до Р-91, — корпус без читателя.

## Объекты, по каждому нужен вердикт

1. Zone Sync Monitor, воркфлоу `f7kdTpDADk7q0v2t` — паспорт называет читателем цикл обслуживания.
2. Журнал `LOG_gap-monitor-findings` — копит находки, забирать некому.
3. Журнал `SYS_INDEX_SIZE_LOG` — замеры размера, потребитель был тот же цикл.
4. Проверка П6 воркфлоу Gap Monitor `5Rs6pNDSm4weWDVj`.
5. Проверка П7 того же воркфлоу.
6. Схема Зоны Б в паспорте Gap Monitor: Зона А уехала в `labs/sys/`, паспорт этого не знает.

## Состояние на 2026-09-27 (сессия SYS, наряд Н-26.09-01)

Седьмой объект, не входивший в список выше, снят по решению владельца 2026-09-26: воркфлоу ротации паролей-канареек «Password Rotation — SYS_INDEX + CORE (daily)» `zOoQ5v92MpBIRKUw` архивирован 2026-09-27; ADR в паспорте `1MGz1KM_WtmPRO3geKJiyUV5vZP5-YXkvoPUBqr3REMY`, адрес восстановления — `projects/git-migration/NOT_TAKEN.md`. Шесть пунктов списка остаются без вердикта. Захвачено попутно, к вердиктам: (а) SYS Lint `TXNstdVL8xlIygBp` читает SYS_INDEX и CORE (узлы 03_Get_SYS_INDEX_Meta, 06_Get_SYS_INDEX_Text, 02_Get_CORE_Meta, 05_Get_CORE_Text по `registry/n8n-map.md`) и, вероятно, сверяет канарейку — после снятия ротации возможен ежедневный ложный алерт; рекомендация сессии — переориентировать на репозиторий или снять; (б) `registry/n8n-map.md` показывает `zOoQ5v92MpBIRKUw` активным до следующего снимка N8N Registry Sync `gFFiBPm1OomOzJOj`; (в) описание архивного воркфлоу называло слово ротации детерминированным по UTC-дате, паспорт (ADR 2026-08-07) — случайным через Math.random; в NOT_TAKEN.md записано по паспорту.

## Рамка решения

Чинить наблюдение достройкой наблюдения запрещено: новый прибор, читающий эти журналы, — то же самое ещё раз. Вероятный исход по каждому объекту — снятие, а не переадресация.

## Условие снятия

По всем шести пунктам есть вердикт владельца: снят, переадресован названному читателю или оставлен сознательно. После шестого — файл и строка INDEX удаляются одним коммитом (§4б.6).
