# Куда класть копию мастер-промпта проекта с личными данными

Метка: РУТИНА, решение Андрея. Заведена 2026-10-24 сессией SYS по захвату типа Идея из онбординга проекта FINANZEN.

## Суть

Метод мастер-промпта (Skill second-brain-engineer, файл references/prompt-craft.md, шаг 6, пункт 3) велит класть английскую копию вставленного промпта в `meta/prompts/<папка>.md` репозитория. Для проекта, чей промпт описывает личные обстоятельства Андрея (структуру доходов, семью, работу), это противоречит запрету на личные данные в публичном репозитории (Skill second-brain-git, инвариант И-7, класс 2). Первый такой случай — FINANZEN: копии промпта положены в папку проекта на Google Drive (строки FINANZEN_PROMPT_EN_red2 и FINANZEN_PROMPT_RU_red2 в `registry/documents.md`), а метод это место не называет.

Второе следствие того же пробела: поиск копий старой формулировки при правке Skill (Skill second-brain-git, файл references/skill-edit.md, пункт 2.6) идёт по `meta/prompts/`; копии на Drive он не видит, и устаревшая строка в промпте FINANZEN останется ненайденной.

## Предложение

Правка Skill second-brain-engineer, файл references/prompt-craft.md, шаг 6, пункт 3: «английский текст — в `meta/prompts/<папка>.md`» дополнить исключением: проект, чей промпт несёт личные данные Андрея, держит обе копии в папке проекта на Drive со строками в `registry/documents.md`, а в `meta/prompts/` — файл-указатель без текста промпта (имя проекта и адрес строки реестра), чтобы поиск копий по пункту 2.6 видел, что копия существует и где её читать. Текст «было → стало» готовится при взятии задачи.

## Условие снятия

Андрей решил: правка внесена в Skill и залита, либо сказано «не нужно». Если репозиторий станет приватным (`labs/sys/t-private-repo.md`), задача теряет смысл.
