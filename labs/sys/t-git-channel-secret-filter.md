# Фильтр секретов в воркфлоу записи Канала

Метка: РЫЧАГ. Заведена 2026-10-18 сессией SYS по решению Б3(б) харвеста 2026-10-18 (файл meta/HARVEST_2026-10-18_answers.md).

## Суть

Инвариант И-7 Skill second-brain-git запрещает писать в публичный репозиторий имена и номера ключей доступа n8n, пути вебхуков, признаки аутентификации. Запрет текстом нарушен пять раз за десять дней (пакет харвеста, находка Б3): правка файла историю не чистит, коммит остаётся навсегда. Правило, исполнимое кодом, переносится в код (Skill second-brain-engineer, references/design.md, пункт 16).

## Предложение

Проверка в воркфлоу записи Канала (Git Write, Git Replace, Git Append, Git Append File, Git Commit Files) до PUT: явный отказ с причиной, если в тексте есть признак секрета. Образец защиты уже работает — воркфлоу снимка registry/n8n-map.md (И-7: строка с «/webhook/», «Bearer», «@» роняет прогон).

## Условие приёмки (из решения Б3(б))

Номер воркфлоу n8n устроен так же, как номер ключа (16 знаков латиницы и цифр), а номера воркфлоу стоят в каноне сотнями. До включения выражение фильтра прогоняется скриптом по всему текущему репозиторию: оно находит только известные нарушения и ни одного номера воркфлоу. Отказ — явный, не молчаливый. Правка воркфлоу Канала — пакетом с перечнем узлов и «да» Андрея (Skill second-brain-engineer, раздел Р10).

## Условие снятия

Фильтр стоит во всех пишущих воркфлоу Канала, прогон по репозиторию дал ноль ложных срабатываний, пробная запись строки с признаком секрета отбита с причиной.
