# Тип входа webhook обязателен при вызове Канала

Суть: `execute_workflow` с типом входа `form` вместо `webhook` даёт отказ «Missing fileId» — он выглядит как ошибка параметров вызова, а не как ошибка формы входа, и потому уводит отладку не туда (исполнение 58023). Обязательность типа `webhook` не зафиксирована ни в Skill, ни в реестре инструментов.

Следующий шаг: внести строку в `registry/tools.md` — тело вызова Канала передаётся полем `inputs` с типом `webhook`; тип `form` и поле `data` не доезжают, отказ маскируется под ошибку параметров.

Условие снятия (дословно из источника): «Готово = строка внесена в google-drive-docs либо в registry/tools.md».
