# Стандарт повторов: три этапа

Суть: замысел — перестать ловить один и тот же дефект заново. Три этапа: микро-чеклист регрессов, правило второго раза, нечёткое сопоставление записей о багах. Расшифровка каждого осталась в Зоне Б SYS_INDEX, которая при переезде остаётся в Google Docs архивом, — то есть у задачи здесь названы только имена этапов.

Следующий шаг: поднять расшифровку из Зоны Б и решить по каждому этапу отдельно — либо этап становится задачей с собственным телом, либо снимается. Без расшифровки задача неисполнима: три имени не говорят, что делать.

Условие снятия: по каждому из трёх этапов есть вердикт; ни один не остался именем без содержания.
