# Защита сессии Claude Project отклоняет часть действий, которые разрешает пакет проекта

**Суть.** В сессии интегратора MARKETPLACE_REBUILD (Claude Project, режим авто) классификатор разрешений отклонил: (1) запуск воркфлоу, работающего через ключ API самого n8n («Credential Exploration») — инструмент копирования воркфлоу `MKT2 Workflow Clone Tool` nXJreKQ9cO7eyMkM; (2) правку опубликованного воркфлоу проекта и замену общей функции базы, которой пользуются другие книги («Modify Shared Resources») — MOUjE526hK78aJOZ и ue.wb_price_rows. Разрешено: создавать новые воркфлоу, привязывать к ним ключи, править и публиковать свои новые воркфлоу, создавать новые объекты базы. Пакет разрешения проекта (PLAN.md раздел 4) эти действия разрешает — защита строже пакета. Подробности — записи Р-75, Р-77, Р-78 журнала projects/marketplace-rebuild/LOG.md.

**Следствие для планов.** Наряд или контракт автопилота, где правка опубликованного или общего объекта выполняется сессией Claude Project, может встать. Обход, который сработал: новый объект рядом со старым (копия функции под новым именем, новый воркфлоу), исходный не трогается; копирование кода узлов — набором с проверкой размера по исходным файлам на Диске.

**Предложение.** (а) В Skill naryad / avtopilot — строка: правку опубликованных и общих объектов планировать в среде, где она разрешена (Claude Code на компьютере Андрея), а в Claude Project — только новые объекты. (б) Решить, оставлять ли инструмент копирования через API n8n: ключ API n8n даёт полный доступ к инстансу.

**Условие снятия.** Строка (а) внесена в Skill или Андрей решил, что не нужна; судьба инструмента (б) решена.
