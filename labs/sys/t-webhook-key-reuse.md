# Вебхуки воркфлоу-инструментов закрыты ключом, который, похоже, служит и рабочим ключом внешнего API

Метка: кандидат в БЛОКЕРы. Заведена 2026-10-16 сессией SYS (Аргус) на !save; находки субагентов сессии 2026-10-14 (чтение всех активных воркфлоу) и наряда Н-16.10-01 (раздел «Находки вне рамки», пункт 4).

## Суть

Репозиторий публичный, поэтому здесь нет имён ключей, их ID и списка вебхуков (инвариант И-7 Skill second-brain-git). Подробности — в чате SYS 2026-10-16 и в позиции AH-19 очереди `registry/maintenance-queue.md`, которая описывает частный случай этой задачи.

Наблюдение (прочитано посредником 2026-10-14 и 2026-10-16): один и тот же ключ доступа n8n типа Header Auth закрывает вебхуки нескольких воркфлоу-инструментов, вызываемых из сессий Claude, и он же используется другим воркфлоу как ключ для обращения во внешний API маркетплейса. Если значение ключа — действующий токен маркетплейса, то пароль вебхуков совпадает с этим токеном: утечка одного открывает другое, а ротация токена молча ломает вызовы вебхуков. Значение ключа никто не смотрел.

Ошибка этой сессии: 2026-10-16 в файл `labs/sys/t-draft-trigger-divergence.md` попали имя и ID этого ключа и признак аутентификации вебхука (дозаписи результата наряда Н-16.10-01 и его приёмки). Коммит в истории публичного репозитория остаётся навсегда; правка файла этого не убирает.

## Следующий шаг

1. Андрей в интерфейсе n8n: открыть этот ключ и сравнить значение с токеном маркетплейса. Только сравнить, значение в чат не присылать.
2. Если совпадает: Андрей создаёт отдельный ключ для вебхуков воркфлоу-инструментов (или ставит уже существующий канальный ключ, которым закрыты вебхуки Git-канала) и привязывает его к узлам-вебхукам этих воркфлоу. Привязка ключа — только рукой Андрея (Skill second-brain-engineer, раздел Р13). После этого записанные имена перестают что-либо открывать.
3. Сессия: после замены — проверить по triggerInfo каждого из этих воркфлоу, что вебхук по-прежнему требует заголовок, и один пробный вызов каждого через MCP; закрыть позицию AH-19 очереди.
4. Решение Андрея: оставить коммиты 2026-10-16 в истории (после шага 2 они безвредны) или переписать историю ветки main — переписывание необратимо для всех клонов и параллельных сессий; рекомендация сессии — не переписывать, а закрыть причину шагом 2.

## Условие снятия

Ключ вебхуков воркфлоу-инструментов отличен от ключа внешнего API (подтверждено Андреем по интерфейсу), вебхуки проверены пробным вызовом, позиция AH-19 закрыта.
