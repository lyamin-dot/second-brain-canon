# Сплошная сверка n8n-workflow-registry

Суть: §1, §3 и §4 Skill `n8n-workflow-registry` устарели — состав, адреса и состояние инстанса разошлись с фактом. Живой состав воркфлоу ведётся в самом реестре n8n, а Skill хранит доменные детали, которых там нет; расхождение делает недостоверным именно то, ради чего Skill читают.

Следующий шаг: сверить каждый параграф §1, §3, §4 с фактом — воркфлоу опросом инстанса, идентификаторы таблиц по реестру. Расхождения собрать одним списком: правка Skill — операция владельца.

Условие снятия: по каждому из трёх параграфов вынесен вердикт «верен» или «исправлено», список расхождений пуст.
