# Токен GitHub Git-канала истекает 2026-11-30

Метка: кандидат в БЛОКЕРы. Заведена 2026-10-09 сессией SYS (Аргус) на !save; находка харвеста 2026-10-08 (`projects/n8n-map/PLAN.md`, вопрос В7).

## Суть

Срок жизни токена GitHub — **2026-11-30 20:34:20 UTC** (`registry/tools.md`, строка «СРОК ЖИЗНИ ТОКЕНА GitHub»; снято из заголовка ответа GitHub, исполнение 64439, 2026-09-18). Токен один на все воркфлоу Git-канала, поэтому в эту дату чтение и запись репозитория из Claude Project остановятся целиком и сразу — включая старт каждой сессии проекта, который читает CORE через Git Read Batch.

Факт записан в реестре, но у него нет ни исполнителя, ни момента: строка «Обновлять до этой даты» никого не назначает. Эта задача — единственное место, где срок стоит как работа.

## Следующий шаг

Владелец выпускает новый токен в GitHub и заменяет его в credential Git-канала в n8n (credential — по книге N8N_CREDENTIALS). Затем сессия проверяет: один вызов Git Read по любому файлу проходит, и новый срок из заголовка `github-authentication-token-expiration` ответа GitHub записывается в `registry/tools.md` вместо старого.

## Условие снятия

В `registry/tools.md` записан новый срок токена, снятый с ответа GitHub после замены, и Git Read после замены прошёл (номер исполнения назван).
