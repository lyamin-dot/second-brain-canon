### Работа 4. Противоречия и устаревшие места, найденные при сверке `apps-script-sheets`

Решение по каждому принимает Андрей.

1. §1, пункт «Прогон»: «Андрей вставляет и запускает `setupAll`». Для книг под clasp слово «вставляет» неверно. Правка 2.3 это покрывает, отдельная правка строки не внесена.
2. §4.3 «Бэкап перед перестройкой»: копия на скрытый лист `_dashboard_backup` хранит данные листа, git хранит код. Они не заменяют друг друга; git данные книги не спасает. Противоречия нет, возможна одна уточняющая фраза.
3. Правило «ИСТОРИЯ ДИАГНОЗА» в §1 про полный текст вместо патчей: для книг под clasp сужено, а не отменено; историю не переписывать.
4. Порядок «pull, потом коммит», предложенный в чате раньше, исправлен в новом Skill на «сначала чистая папка, затем pull»: clasp pull затирает локальные несохранённые файлы.
