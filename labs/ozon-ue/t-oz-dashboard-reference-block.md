# Витрина oz_dashboard: блок «справочно»

Суть: построить на витрине `oz_dashboard` блок «справочно» — Продаж шт, Возвраты шт, Средний чек — когда эти метрики появятся на уровне `oz_weekly_history`. Сейчас их нет ни там, ни в `oz_cost_monitor`.

Следующий шаг: дождаться метрик в `oz_weekly_history` (или добавить их), затем построить блок.

Условие снятия: блок на витрине зеркалит строки `oz_cost_monitor` и виден при чтении живой книги.
