# Пробный период SelSup: три проверки на трёх кабинетах

Суть: пробный период SelSup — 7 дней бесплатно. Подключить оба кабинета Ozon и кабинет WB и проверить три вещи: встают ли оба юрлица Ozon в один аккаунт SelSup; связываются ли уже существующие карточки Ozon по артикулу продавца `offer_id`; доходит ли правка описания одной карточки до всех трёх кабинетов. Заодно запросить у поддержки SelSup документацию API. Контекст выбора: контент карточек ведётся в готовом сервисе управления карточками, цена считается отдельно для каждого из трёх кабинетов (решения Андрея 2026-09-28, Зона Б, блок «Система управления карточками на трёх кабинетах»).

Следующий шаг: Андрей запускает пробный период; по каждой из трёх проверок записать результат «да» или «нет».

Условие снятия: по каждой из трёх проверок записан результат да или нет (в источнике — в Зоне Б; в repo — дозаписью в эту задачу до её закрытия), документация API запрошена.
