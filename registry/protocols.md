# Реестр кросс-проектных протоколов

Что это: идентификаторы и назначение протоколов, которыми пользуются несколько проектов, и запись об упразднённом реестре источников Skills. До 2026-09-10 — Раздел 14 CORE (файл `core/R-14.md`); перенесён в `registry/` решением Р-66 журнала `projects/git-migration/LOG.md`.

Кто читает и когда: сессия, которой нужен конкретный протокол или его идентификатор; обслуживание при проверке реестра протоколов. На старте сессии и при чтении CORE по Манифесту этот файл не читается. Ссылка «CORE Р.14» означает этот файл.

Как перенесено: блоки T-NN взяты целиком, с провенанс-маркерами; текст строк не правился, серии пустых строк сокращены до одной. Второй реестр протоколов — документ SYS_PROTOCOL_REGISTRY в Google Docs (`registry/documents.md`, блок T-012) — существует параллельно; их сведение — отдельное решение, этим переносом не принималось.
