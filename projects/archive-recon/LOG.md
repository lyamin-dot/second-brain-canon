Р-5 | В СИЛЕ | 2026-09-25 | какой инструмент использовать для извлечения автор/журнал/год/DOI, когда настанет Ф3
  принято: законсервировать выбор до старта Ф3 (Ф2 не пройдена); из исследования Gemini Deep Research (по запросу этой сессии) зафиксировать выводы на будущее: связка Docling (IBM, конвертация PDF в чистый текст/Markdown, справляется со сложной немецкой вёрсткой — врезки, таблицы, S3/AWMF-руководства) → pdf2doi или регулярка по тексту (поиск DOI) → CrossRef API по найденному DOI (habanero или crossref-commons, чистые автор/журнал/год) — выглядит подходящей основой. GROBID — альтернатива с собственной сегментацией (F1 0.80–0.89 на английском, ниже без дообучения на немецком). Embedded-метаданные PDF (exiftool/PyPDF2/XMP) — по данным исследования ненадёжны систематически, не только для наших файлов: поле Author часто содержит имя ПО, Title — техническое имя файла при сохранении. Zotero/Mendeley/Paperpile — для ручной работы годятся, для автоматизированного конвейера extract-to-spreadsheet — нет
  почему: связка CrossRef+DOI работает только для документов, зарегистрированных издателем — это исключает именно немецкие guideline-документы (AWMF, S3-Leitlinien), которых в архиве много (см. .lnk-ярлыки на Leitlinien в Regionale A и Sedierung, Ф1 STATE.md); как закрывать этот случай, присланный текст не покрывает (обрывается на сравнительной таблице) — открытый вопрос на момент запуска Ф3, не на сейчас
  кто подтвердил: Андрей — заказал исследование и прислал результат для фиксации
