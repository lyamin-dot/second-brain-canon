# archive_scan.py — опись архива документов

Версия 1.2. Восстановлена 2026-10-10 по описанию записи Р-15 (пункт 1) журнала проекта: файл от 2026-09-27 утерян, это новое написание, а не копия. Роль файлов этой папки — «инструмент проекта», объявлена в PLAN.md (раздел «Справочные материалы и инструменты») и записана в LOG.md.

Скрипт обходит папку целиком и ничего не меняет в ней. Токены Claude он не тратит.

## Что нужно

- Python 3.8 или новее.
- `pip install pymupdf` — чтение PDF.
- Для ключа `--ocr`: Tesseract с языковыми данными `deu` и `eng` (на Windows — установщик UB Mannheim; при установке отметить German). Если программа не в PATH, путь задаётся ключом `--tesseract`.
- Для `--crossref`: интернет. Электронная почта для «вежливого» пула CrossRef — параметр запуска `--email` или переменная окружения `CROSSREF_EMAIL`. В коде её нет, и в репозиторий её класть нельзя: репозиторий публичный.

## Запуск

```
python archive_scan.py "G:\Мой диск\...\AA Beruf" --out "G:\Мой диск\...\папка-выгрузок" --ocr --crossref --save-text --email вы@пример.org
```

Папка выгрузок (`--out`) не должна лежать внутри репозитория и внутри сканируемой папки. В выгрузках личные пути и чужие тексты первых страниц.

| Ключ | Что делает |
|---|---|
| `--out` | папка для выгрузок (обязателен) |
| `--crossref` | по DOI добавляет авторов, журнал, год и название из CrossRef; отмечает, принадлежит ли DOI этому файлу |
| `--email` | почта для CrossRef (или `CROSSREF_EMAIL`) |
| `--ocr` | распознаёт Tesseract'ом (deu+eng) первые страницы PDF без текстового слоя |
| `--save-text` | сохраняет текст первых страниц в `OUT/texts/` (по одному файлу на PDF) |
| `--text-pages N` | сколько первых страниц сохранять и распознавать, по умолчанию 3 |
| `--hash-video` | считать md5 и у видеофайлов (по умолчанию видео только перечисляется) |
| `--tesseract` | путь к tesseract, если его нет в PATH |

Повторный запуск не перечитывает неизменённые файлы (совпали путь, размер и время изменения) и не повторяет запросы CrossRef по уже известным DOI: кэш — `scan_cache.sqlite` в папке выгрузок. Изменили `--text-pages` — файлы перечитываются.

## Что получается

- `files.csv` — строка на файл: путь, папка, размер, даты, md5, `doc_type` и `doc_type_rule` (правило, определившее тип), число страниц, есть ли текстовый слой, DOI с источником и списком кандидатов, `doi_belongs`, данные CrossRef, номер реестра AWMF, класс и вариант руководства, год с источником (`year_source`) и всеми кандидатами (`year_candidates`), статус мемокарты, номера групп повторов, `text_file`, `error`.
- `folders.csv` — строка на папку: число файлов, размер, `read_ok`.
- `guidelines.csv` — руководства по номеру AWMF и варианту: год и `version_status` (`newest`, `older`, `single_version`, `unknown_year`).
- `duplicates.csv` — повторы трёх видов: `copy` (побайтная копия, одинаковый md5), `same_doi` (один DOI, разные байты), `similar_title` (похожее название при числе страниц, различающемся не более чем на 2).
- `summary.txt` — сводка.
- `texts/` — тексты первых страниц (при `--save-text`).
- `scan_cache.sqlite` — кэш.

## Как читать результат

**Полнота обхода.** Раздел «FOLDERS THAT COULD NOT BE READ» в `summary.txt` есть всегда. Обход полный, только если там написано `(none)`. Если папки не открылись, скрипт пишет это в `summary.txt`, в окно и завершается с кодом 2. Причина — тупик Т-3 журнала: версия 1.0 молча пропускала подпапки, которые Google Диск для компьютера не отдавал. Раздел «ENTRIES SKIPPED» перечисляет ярлыки-ссылки и прочее, во что скрипт не заходил. Колонка `online_only` в `files.csv` отмечает файлы, которые Диск ещё не скачал на компьютер.

**DOI.** Источники по убыванию: имя файла (в том числе имена Springer вида `s44180-021-0018-7.pdf`, префикс издателя при этом угадывается — `10.1007`, `10.1186`, `10.1038` — и проверяется в CrossRef), врезка «Bibliografie» / «Zitierweise» на страницах до 40-й, первые две страницы. DOI с первых страниц может принадлежать не самой статье, а процитированной. Без `--crossref` проверить это нельзя: `doi_belongs = not_checked`. С `--crossref` название по DOI сверяется с текстом первых страниц: `yes` (≥ 70% значимых слов совпало), `maybe` (≥ 40%), `no`, `unknown` (в файле нет текста), `not_found` (CrossRef такого DOI не знает). Для повторов «один DOI» берутся только DOI не со значением `no` / `not_found`.

**Год.** `year_source` называет источник; приоритет: CrossRef (если DOI принадлежит файлу), текст («Published», «Stand», ©), дата в имени файла, год в имени файла, год из DOI Springer, год в имени папки, `filename-cme-cycle`, метаданные PDF, самый частый год на первой странице. Год цикла CME в имени («CME 03.26») — это не год публикации, поэтому приоритет у него низкий.

**Мемокарта.** `done` — рядом (в той же папке) есть файл `… MM.pdf` или `.mom` с совпадающим названием; `missing` — в пути есть пометка «OHNE MM» / «MM fehlt» и карты нет; `none` — карты нет и пометки нет; `card` — сам файл является картой; `n/a` — не PDF. Слово «готово» ставится только по найденному файлу.

**Тип документа.** Правила проверяются по порядку, побеждает первое сработавшее, и оно записано в `doc_type_rule`. Порядок: расширение (не PDF), мемокарта, руководство AWMF, сертификат, статья CME, презентация (альбомная ориентация, до 80 страниц, без DOI), журнальная статья (есть DOI или Abstract + Introduction/Methods), SOP/стандарт, книга (от 120 страниц), скан без текста, прочее. Правила эвристические: тип — подсказка для разбора, а не окончательный вердикт.

**Повторы похожего названия.** Название берётся из CrossRef, иначе из метаданных PDF, иначе из имени файла (без «Kopie», дат и номеров); сравниваются названия длиннее 11 знаков со сходством ≥ 0,9.

## Ограничения

- Одна нитка, без параллелизма: 736 файлов с CrossRef занимали порядка семи минут; главный архив (около 70 ГБ) займёт заметно дольше — запускать на ночь, кэш позволяет прервать и продолжить.
- Видео не хешируются, пока не задан `--hash-video`, поэтому повторы среди видео без ключа не находятся.
- Повторы ищутся только внутри одного обхода: два обхода разных частей архива друг друга не видят.
- Файлы больше 300 МБ читаются дважды (md5 и разбор).
- Тексты PDF без текстового слоя доступны только при `--ocr`.
