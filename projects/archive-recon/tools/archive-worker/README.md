# archive-worker — распознавание книг архива на сервере

Рабочий контейнер по плану `projects/archive-recon/SERVER_PLAN_ocr.md`. Два файла: `worker.py` (весь код) и `Dockerfile`. Пути на сервере, адреса и номера здесь не пишутся: репозиторий публичный, они — в снимке сервера в проекте «01_Развитие сервера».

## Что делает
Постоянно работающий процесс. Раз в час сверяет папку очереди на Диске (rclone, только чтение) и добавляет новые PDF — по типу файла, а не по расширению. Берёт книги по одной, по очерёдности: скачивает, сверяет контрольную сумму с Диском, определяет язык, распознаёт КАЖДУЮ страницу, снимает текстовый слой, пишет в индекс, удаляет скачанный файл. Каждая страница сохраняется сразу, поэтому после перезапуска книга продолжается с места остановки.

На страницу три текста: `layer` — слой как есть; `ocr` — распознанный текст как есть; `ocr_search` — распознанный текст со склейкой переносов на месте. Индекс полнотекстового поиска — две таблицы: по слою и по поисковому тексту распознавания; каждое совпадение несёт источник `layer`, `ocr` или `both`.

Язык: три пробные страницы (на четверти, половине и трёх четвертях книги — обложки не годятся для пробы) распознаются сразу английским, немецким и русским; дальше по доле кириллицы и по служебным словам выбирается `rus`, `deu`, `eng` или их сочетание. Уверенность распознавания между разными языковыми моделями плохо сравнима, поэтому выбор идёт по тексту, а уверенность сохраняется по каждой странице (`ocr_conf`).

Склейка переноса: слово-дефис-перевод строки-слово, по умолчанию не короче двух букв с каждой стороны; одна пустая строка между частями допускается (Tesseract ставит её после короткой строки). Если вторая часть с заглавной буквы — дефис сохраняется (`Herz-Kreislauf`). Параметры меняются через управление, поисковый текст пересобирается без повторного распознавания.

Остановки: свободно меньше `MIN_FREE_GB` (по умолчанию 20 ГиБ) — пауза; три книги подряд с ошибкой — пауза; сломанная книга получает статус `error` с текстом ошибки, работа идёт дальше.

## Интерфейс (только внутри своей сети контейнеров, порт 8080, наружу не публикуется)
- `GET /health` — жив ли процесс.
- `GET /status` — пауза и её причина, текущая книга и страница, свободное место, настройки, счётчики по статусам, строка на каждую книгу: страниц, страниц со слоем, распознано, язык, разрешение, ошибка.
- `GET /search?q=…&limit=10&book=<id>` — совпадения: книга, страница PDF, печатный номер страницы (`label`), источник, сниппеты.
- `GET /page?book=<id>&page=<n>` — три текста страницы, печатный номер, уверенность.
- `GET /toc?book=<id>` — оглавление из закладок PDF.
- `POST /control/<действие>` с телом JSON — только данные и параметры, код не принимается:
  - `pause`, `resume`, `rescan` (сверить папку очереди сейчас), `rebuild_search` (пересобрать поисковый текст всех книг);
  - `settings` — `{"default_dpi": 150..400, "keep_upper_hyphen": true|false, "min_letters": 1..5}`;
  - `book` — `{"id": N, "op": "requeue"|"enqueue"|"skip"|"priority"|"lang"|"dpi", "value": …}`: `requeue` — заново с нуля, `enqueue` — продолжить, `priority` 0..1000 (меньше — раньше), `lang` — только `eng`, `deu`, `rus` и их сочетания через `+`, или `null` для автоопределения, `dpi` — целое 150..400 или `null`.
  Всё прочее отклоняется ответом 400: язык и разрешение попадают в команду распознавания.

## Блок compose
```
  archive:
    build: ./archive
    restart: unless-stopped
    read_only: true
    tmpfs: [/tmp]
    cap_drop: [ALL]
    security_opt: ["no-new-privileges:true"]
    volumes:
      - <папка архива на хосте>:/data
      - <папка ключа drive-reader на хосте>:/secrets:ro
    networks: [archive]
    deploy:
      resources:
        limits: {cpus: "1.5", memory: 1536M}
```
У сервиса n8n добавляется `networks: [default, archive]`, на верхнем уровне — `networks: {archive: {}}`. Индекс пишется в `<папка архива>/ocr/index.sqlite`; прежний индекс прототипа не трогается.

## Обновление кода — только командой владельца
Новая версия берётся по номеру коммита, контрольная сумма сверяется с названной агентом сервера, затем `docker compose build archive && docker compose up -d archive`. Автоматической подтяжки нет (решение владельца 2026-10-21, план, раздел «Отклонено»).

## Проверка на образцах (2026-10-21, рабочая среда агента сервера; Tesseract 5.3.4, PyMuPDF 1.28.2)
Четыре файла: PDF со слоем и рисунками с подписями (английский, печатные номера с 19, оглавление), скан без слоя на русском, скан без слоя на немецком без расширения `.pdf`, сломанный файл. Итог: три книги `done`, сломанная — `error`, работа не встала; язык определён `eng`, `rus`, `deu`; подпись рисунка находится только в распознанном тексте (`source: ocr`), в слое её нет; `contralateral`, `противоположной` и `Herz-Kreislauf` находятся после склейки переноса; печатные номера и оглавление отдаются; недопустимые язык, разрешение, номер книги и действие отклоняются. Сборка образа в рабочей среде не проверялась (нет Docker) — первая сборка на сервере и есть её проверка.
