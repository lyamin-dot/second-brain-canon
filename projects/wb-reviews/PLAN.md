## Граница базы знаний и правило T1

- РЕШЕНИЕ АНДРЕЯ 2026-07-29 — ГРАНИЦА АВТОРИТЕТНОСТИ БАЗЫ ЗНАНИЙ (меняет цель Фазы 2, читать перед любой работой над промптами агентов). Знания допусков масла НЕДОСТАТОЧНО для официального ответа «подходит или нет». Такой ответ требует обратного направления — «марка + тип двигателя + год выпуска → требуемая спецификация», то есть базы по АВТОМОБИЛЯМ, которой в проекте НЕТ и которая НЕ СТРОИТСЯ (TecDoc-класс задачи, не окупается при 48 обращениях/мес). СЛЕДСТВИЯ: (а) наша KB обслуживает ТОЛЬКО простые товарные вопросы (что это, объём, вязкость, состав упаковки, наличие, подлинность); (б) правило T1 УЖЕСТОЧАЕТСЯ — система не даёт заключения о пригодности масла для конкретного авто НИКОГДА, а не «при недостатке данных»; маршрут — официальный подборщик Liqui Moly плюс инструкция автомобиля; (в) при этом ошибки в KB устраняем, но авторитетность KB в абсолют не возводим — формулировка Андрея; (г) stroke_type при этой рамке нужен не для рекомендации, а для КОРРЕКТНОГО ОТКАЗА: признак, по которому система отличает масло для двухтактной техники от автомобильного и отказывается отвечать вместо того чтобы угадать.
