# PLAN_content — карточки товаров Liqui Moly для Wildberries и Ozon (инфографика)

Канон перенесён 2026-11-06 из Google Doc CONTENT_INDEX (заморожен; ID — `registry/documents.md`) решением Андрея в чате Claude Project «Создание контента» (запись Р-1 журнала `LOG.md`). Агентская копия контракта автопилота — `PLAN.en.md` (правка одного файла пары — тем же коммитом правка другого).

## Цель

Слайды-инфографика (8 штук, 1200×1600) для карточек товаров магазина 112Oil на WB и Ozon, которые поднимают переход в карточку и конверсию. Первый финиш — утверждённый эталон на четырёх товарах; второй — пилот на 10–15 товарах с замером; третий — конвейер на весь ассортимент. Видео в этот цикл не входит (Р-2).

## Что сохранено из прежней работы (решения 2026-06-27/28, источник — Зона Б замороженного CONTENT_INDEX)

1. Бренд — айдентика Liqui Moly; Андрей — официальный продавец (сертификат дистрибьютора Аллея Групп). Бейдж «Официальный продавец / Гарантия подлинности» — на слайдах 2–8.
2. Палитра: #C8102E (красный Liqui Moly, акцент), #1A1A1A (тёмный фон), #F8F8F8 (светлый фон), #FFFFFF (текст на тёмном); не больше трёх цветов на слайде; синий #003087 — только редким разделителем.
3. Шрифт Montserrat: H1 ExtraBold 72–96 px, H2 SemiBold 48–60 px, текст Regular 36–44 px, жёсткий минимум 28 px.
4. Сетка 1200×1600: поля 48 px; безопасная зона сверху 60 px, снизу 80 px (элементы интерфейса площадок); зоны: верх — логотип и бейдж, центр-верх — товар, центр — заголовок и обещание, низ — техданные и бейджи.
5. Логотип: верхний левый или правый угол, ширина не меньше 180 px, отступ 48–60 px. Официального файла логотипа в проекте нет — до его появления на месте логотипа нейтральная заглушка «ЛОГО», рисовать логотип по памяти нельзя.
6. Эталонная четвёрка (максимально разные типы): 1340 герметик системы охлаждения (невидимый механизм), 1342 промывка двигателя Engine Flush (до/после), 1750 очиститель стёкол Cherry (лёгкая косметика), 1709 спрей от грызунов (аномалия).
7. Приоритет конвейера — по спросу; список из 23 артикулов, данный Андреем 2026-06-27: 1340, 1709, 1368, 1761, 1338, 1360, 1706, 1702, 1341, 1718, 1708, 1366, 1342, 1778, 1755, 1719, 1750, 1339, 1712, 1751, 1333, 1361, 1347.
8. У автохимии нет допусков API, ACEA, SAE и OEM — слайд «стандарты» заменён на «назначение и применение».
9. Канистра — реальное фото товара, нейросеть делает только окружение; текст и инфографику собирает шаблон, не генератор картинок.

## Устройство (решение Р-2)

- Рендер — в песочнице сессии Claude Code: HTML/CSS → PNG через Playwright (Python) и установленный `/usr/bin/google-chrome`; шрифт Montserrat из npm (`@fontsource/montserrat`, кириллица), иконки — SVG из npm (`lucide-static`). Сеть песочницы не видит Google Fonts, CDN Wildberries и Ozon (проверено 2026-11-06): всё внешнее — через npm или Google Drive.
- Фото товаров — папка Drive «фото-товаров» (ID — `registry/documents.md`), имя файла начинается с артикула (`1340_1.png`). Песочница получает файл через `download_file_content` коннектора Drive: ответ выше предела ложится файлом на диск, байты совпали с Drive (проба 2026-11-06, 161 276 Б). Фото нет — серый силуэт канистры с подписью «фото товара».
- Фоны — кодом (градиенты, геометрия, свет), решение Андрея 2026-11-06; промпты для нейросети готовятся в эталоне, генерация — после утверждения.
- Источник данных — лист `kb_auto_chemistry` книги «02 Автокосметика 25.08 Сравнение WB und Ozon» (ID `1sPD5SAFCTygzUaEPg8RKRPHQyc0HCMIK-aMpnXqYu3k`), читать gsheets-read; лист «Фото» той же книги — ссылки на фото текущих карточек (не трогаем без отдельного решения).
- Показ результата — закрытая страница-артефакт с галереей PNG; PNG в репозиторий не кладутся (репозиторий публичный).
- Серверный рендерер (контейнер `playwright`) — не используется: на 2026-10-13 в состоянии «exited» (`projects/archive-recon/SERVER_TASKS.en.md`, строка 18). Конвейер на n8n — после утверждения эталона, отдельным решением.
