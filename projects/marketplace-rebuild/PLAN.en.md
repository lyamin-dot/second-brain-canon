1 Correctness: old outputs vs primary source (marketplace report, cabinet, document; UE = marketplace financial report for a chosen period; declarations = Liqui Moly site + declaration text). Andrei defines "correct" + tolerance per area in one answer before audit.
2 Reliability: share of failed and empty ("green, no data") executions over last month.

4 Dead weight: steps/sheets/workflows whose output nobody reads.
Output: one table per area, 3 columns: carry as-is | carry with fix (error named) | do not carry (reason). Goes into the area's detailed plan; Andrei decides disputed rows only.
Switch-over reconciliation = against PRIMARY SOURCE, not old version (matching a wrong old version only proves the error was copied). Old = secondary reference; new matches source but differs from old -> old's error found, logged.
