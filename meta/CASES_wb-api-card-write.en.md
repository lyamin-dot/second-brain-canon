Endpoints: write POST content-api.wildberries.ru/content/v2/cards/update (array of cards); read POST /content/v2/get/cards/list (filter.textSearch=nmID); errors POST /content/v2/cards/error/list.

## RULES
1. 200 + empty error = queued, NOT applied. Accept only by re-reading the card (documents number/startDate/endDate/verdict, needKiz, kizMarked, characteristics) + error list. 45 s is enough.
2. cards/update replaces the whole card: send all chars to keep, sizes (chrtID, skus), dimensions, title, description, brand, vendorCode. Omitted = gone.
3. ALWAYS send needKiz, default = value read from card (case 3).
4. Declaration: send chars 15001135 (no), 15001137 (date_from), 15001138 (date_to) AND documents.items [{type:2, number, startDate:"YYYY-MM-DDT00:00:00Z", endDate:"YYYY-MM-DDT00:00:00Z", isEndless:false}] in the same request (cases 1, 2).
5. Chars dates: array of string DD.MM.YYYY, e.g. ["18.09.2026"] (case 5).
6. "OK" = number AND both dates match the source of truth (case 8). WB verdict valid proves nothing about correctness (case 9).
