# NARYAD_file-migration — шаблон наряда на перенос файла [источник: раздел 13, введён 2026-09-02]

Назначение: единая форма наряда для каждого следующего документа системы; подставляются только поля в угловых скобках, остальное неизменно.
Обязательное предусловие: экзамен Контролёра по документу составлен и запечатан ДО триажа (`meta/PROTOCOL_file-migration.md`, п. 10.1 «Экзамен Контролёра»). Нет экзамена — перенос не начинается.
Задача: перенести золото документа `<ИМЯ>` (`<ID>`) в repo `lyamin-dot/second-brain-canon`, каталог триажа `<ID_КАТАЛОГА>`. Порядок: (1) прочитать каталог и источник через gdocs-read, сверить снимок источника с зафиксированным в каталоге (расхождение значит источник изменился — стоп); (2) отфильтровать блоки ЗОЛОТО, сумма байтов обязана сойтись с `<N_БАЙТ>`; (3) сгруппировать по правилу ниже; (4) записать git-write, каждый файл проверить независимым git-read и локальным пересчётом blob SHA-1.
Правило группировки: один файл на нумерованный раздел источника, путь `<ПРЕФИКС>/R-NN.md`, блоки внутри по возрастанию байтового адреса. Материал вне нумерованных разделов номера не получает: шапка → `/meta/header.md`, реестры ID и инструментов → `/registry/`, пароли-канарейки → `/meta/canary.txt`. Зона неочевидна — отказ по мандату, не догадываться.
DoD: (1) таблица файл → newSha → sha независимого git-read → локальный blob SHA-1, три числа на файл, все совпадают; (2) перенесено ровно `<N_БЛОКОВ>` блоков, таблица T-ID → файл на все; (3) текст каждого блока совпадает с источником посимвольно, нормализация переводов строк названа явно; (4) git-log после переноса: коммитов равно числу файлов (см. оговорку в `projects/git-migration/STATE.md`, уточнение 14.1(в)); (5) журнал хода по naryad §6.
Рамка: источник не править, только читать; каталог не править; Docs не замораживать и маркеров не ставить; мастер-промпты не трогать; АРХИВ и ШУМ не переносить; в repo ничего не удалять; папку `test` не трогать.
Мандат на отказ: процедура, посылка, цифры (сумма золота не сошлась — стоп с предъявлением), вход (каталог непригоден, зона блока неопределима, токен не пишет).
Требует: чтение Drive (gdocs-read через n8n), git-read и git-write через n8n, локальные вычисления над текстом.
Паспорт: N = число файлов, R = 2. Прораб пересчитывает паспорт от факта до начала работ, оценка Руководителя не связывает (см. находку 12.9 в `projects/git-migration/LOG.md`). Потолок naryad §3.7 превышается всегда — исполнитель Прораб, дробление по 5 файлов на дочерний, одна сессия, один сводный отчёт.
