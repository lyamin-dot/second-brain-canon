# Карта: раздел CORE → файлы

Читается, когда ссылка вида «CORE Р.N» встречает более одного файла в `core/` или не находит файла `core/R-NN.md`. Для разделов, не перечисленных ниже, действует равенство «один раздел = один файл `core/R-NN.md`».

## Разделы, вынесенные из core/

С 2026-09-10 (решение Р-66 журнала `projects/git-migration/LOG.md`) три раздела лежат вне `core/` и в Манифест не входят: это реестры, из которых берут одну строку в момент использования, а не правила, которые нужны каждой сессии. Ссылка «CORE Р.N» на них разрешается так:

| Раздел | Адрес | Блоки | Что в нём |
|---|---|---|---|
| Р.1 | `registry/projects.md`, секция «Проекты с INDEX в Google Docs» | T-002, T-004 | веса проектов для !priority, карточки проектов |
| Р.2 | `registry/documents.md` | T-005…T-107 | идентификаторы документов и папок Google Drive |
| Р.14 | `registry/protocols.md` | T-097…T-105 | реестр кросс-проектных протоколов |

Запись в эти разделы (новый идентификатор, новый проект, новый протокол) идёт в эти файлы по контракту записи `second-brain-git` §8; в `core/` она не возвращается.

Блоки перенесены побайтово по строкам (серии пустых строк сокращены до одной); сверка непустых строк источника и цели — 0 расхождений. Файлы в том виде, в каком они лежали в `core/`, читаются через Git Read с полем `ref` = `da555174448408b457cedcda495dc39558475601` (последний коммит, где они живы) и путями `core/R-01.md`, `core/R-02a.md`, `core/R-02b.md`, `core/R-02c.md`, `core/R-02d.md`, `core/R-14.md`.

## Источник разреза: адрес в истории

Монолиты `core/R-02.md`, `core/R-06.md`, `core/R-12.md` удалены из ветки `main` 2026-09-06 (наряд Н-06.09-04). Разрез этим закрыт по `second-brain-git` §2a.7: второго носителя трёх разделов в ветке больше нет, и запись в подфайл не оставляет рядом монолит со старым текстом.

Источник при этом не уничтожен. Последний коммит, в котором все три монолита живы, — `0444c0776bc53434b022b2fc6834b61870960cb9` (родитель коммита удаления). Читается тем же каналом: `git-read` с полем `ref` = этот sha и путём монолита. Приёмка разреза по §2a.8 остаётся выполнима буквально: удалённый оригинал есть с чем сверять.

Гейт перед удалением (наряд Н-06.09-04, п.1): конкатенация подфайлов сверена с монолитом побайтово, совпало полностью — R-02 12 854 Б, R-06 17 050 Б, R-12 24 290 Б, расхождений 0. Удаление выполнено тем же вызовом `git-commit`, что и правка этого файла и `core/MANIFEST.md`: промежуточного состояния, где список уже сокращён, а монолиты живы, не существовало.

Провенанс: разрез выполнен по ревизии `denken` Р2 от 2026-09-04 (проект `git-migration`), сессия Cowork; удаление монолитов — 2026-09-06, наряд Н-06.09-04, сессия Cowork.
