# Карта: раздел CORE → файлы

Читается, когда ссылка вида «CORE Р.N» встречает более одного файла в `core/`. Для разделов, не перечисленных ниже, действует прежнее равенство «один раздел = один файл `core/R-NN.md`».

Причина файла: `core/R-02.md`, `core/R-06.md`, `core/R-12.md` превысили целевой потолок 1–5 КБ на файл (`second-brain-git` §2) и разрезаны на подфайлы по границам провенанс-маркеров T-NN. Разрез не трогает содержимое — только границы файлов; побайтовая идентичность с исходником проверена конкатенацией при разрезании.

| Раздел | Файлы (по порядку) | Блоки | Байт |
|---|---|---|---|
| Р.2 | R-02a.md, R-02b.md, R-02c.md, R-02d.md | T-005…T-039 | 4231 / 2311 / 3606 / 2706 |
| Р.6 | R-06a.md, R-06b.md, R-06c.md, R-06d.md | T-044…T-054 | 4931 / 3613 / 5709 / 2797 |
| Р.12 | R-12a.md…R-12g.md | T-067…T-087 | 2871 / 3025 / 4427 / 4783 / 1788 / 5132 / 2264 |

Два файла превышают потолок фактом, не по ошибке разреза: `R-06c.md` (T-053, правило потокового вытеснения ≤2 КБ, 5709 Б) и `R-12f.md` (T-084, регламент исполнения обслуживания п.1–9, 5132 Б) — единственные блоки во всех трёх разделах, которые сами по себе больше целевого потолка. Границ для дальнейшего разреза внутри этих двух блоков в исходнике нет; дробление ниже уровня T-блока — отдельное решение по содержимому, не сделано на этом проходе.

## Источник разреза: адрес в истории

Монолиты `core/R-02.md`, `core/R-06.md`, `core/R-12.md` удалены из ветки `main` 2026-09-06 (наряд Н-06.09-04). Разрез этим закрыт по `second-brain-git` §2a.7: второго носителя трёх разделов в ветке больше нет, и запись в подфайл не оставляет рядом монолит со старым текстом.

Источник при этом не уничтожен. Последний коммит, в котором все три монолита живы, — `0444c0776bc53434b022b2fc6834b61870960cb9` (родитель коммита удаления). Читается тем же каналом: `git-read` с полем `ref` = этот sha и путём монолита. Приёмка разреза по §2a.8 остаётся выполнима буквально: удалённый оригинал есть с чем сверять.

Гейт перед удалением (наряд Н-06.09-04, п.1): конкатенация подфайлов сверена с монолитом побайтово, совпало полностью — R-02 12 854 Б, R-06 17 050 Б, R-12 24 290 Б, расхождений 0. Удаление выполнено тем же вызовом `git-commit`, что и правка этого файла и `core/MANIFEST.md`: промежуточного состояния, где список уже сокращён, а монолиты живы, не существовало.

Провенанс: разрез выполнен по ревизии `denken` Р2 от 2026-09-04 (проект `git-migration`), сессия Cowork; удаление монолитов — 2026-09-06, наряд Н-06.09-04, сессия Cowork.
