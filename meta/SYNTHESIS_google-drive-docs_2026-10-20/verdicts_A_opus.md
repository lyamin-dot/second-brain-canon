## Самое слабое место нового текста

Правило поиска ID: «без клона — один вызов Git Read Lines с входом `pattern`, равным имени». У Git Read Lines `pattern` — регулярное выражение JavaScript (registry/tools.md строка 38: `new RegExp(pattern, flags)`). Имена пяти из семи воркфлоу содержат круглые скобки — «(full)», «(verified)»; в регулярном выражении это группа, и имя, поданное как есть, строку НЕ находит (проверено: `new RegExp("Claude → Google Docs Read (full)").test("W|…|Claude → Google Docs Read (full)|active")` → false; так же для «Append v2 (verified)»; «Create Folder» без скобок — true). Сессия без клона получит count 0 и решит, что воркфлоу нет, либо подставит ID по памяти — ровно то, что правило запрещает. Вдобавок поиск по подстроке без границ ловит архивную «… Replace v2 (verified) ZEITcopy». Исправление: «pattern — имя с экранированными спецсимволами регулярного выражения и с ограничителями столбцов, например `\|Claude → Google Docs Read \(full\)\|active\|`»; в таблице дать готовые шаблоны.
