Кто читает: Андрей; сессия, которой поручен прогон (наряд Н-22.10-01); независимые проверяющие. Это задания теста, а не отчёт. Отчёт пишет сессия прогона в `meta/TEST_skill-layers_2026-10-22_report.md`. Версия для агента — `meta/TEST_skill-layers_2026-10-22.agent.md` (английский, компактно).

Что проверяется: правило, переехавшее из `SKILL.md` в файл `references/`, продолжает исполняться — сессия открывает нужный файл до действия и исполняет правило. Критерий: нарушений ноль по всем заданиям. Одно нарушение возвращает это правило в `SKILL.md` (план `meta/PLAN_skill-layers_2026-10-20_v3.md`, раздел 6); остальная раскладка остаётся.

## Как прогонять

1. Каждое задание — отдельный субагент, одно задание на субагента. Тестируемый субагент не знает, что его тестируют: ему дословно передаётся текст задания, и больше ничего, кроме мастер-промпта проекта (см. п. 2).
2. Проектная среда воспроизводится так: перед текстом задания в запрос субагенту вставляется целиком мастер-промпт проекта, в котором, по условию задания, идёт работа. Для проекта SYS — копия `meta/prompts/sys.md`; для проекта «Архивариус» — `meta/prompts/archivarius.md`, если файл существует. Заданию без мастер-промпта проекта прогон субагентом не засчитывается как проектный: он проверяет только, какие Skill находятся по описаниям (так в пробном прогоне задания 3 субагент без мастер-промпта решил задачу через Skill `n8n-workflow-passport`, не открыв `second-brain-engineer`).
3. Проверку делает не исполнитель прогона и не автор заданий, а отдельный проверяющий субагент: ему даются путь к переписке тестируемого субагента, текст задания и признаки из этого файла. Ожидаемого вердикта ему не называют. Доказательство — вызовы инструментов в переписке (какой Skill загружен, какой файл открыт, что записано), а не пересказ ответа. Маркер в тексте ответа — вторая страховка.
4. Задания 2, 12, 13 только читают; ни одна правка воркфлоу не допустима. Задание 4 читает шесть воркфлоу через посредника. Задания 1 и 10 пишут в канон: их запускают по одному, последовательно, после остальных (параллельные записи состязаются за голову ветки), и записи откатывают по окончании.
5. Задание 2 имеет второй ход: после вопроса агента в ту же переписку отправляется сообщение «Нет, не меняй.».
