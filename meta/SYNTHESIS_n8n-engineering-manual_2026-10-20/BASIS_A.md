## Случаи без адреса

Случаи, рассказанные только в тексте Skill; адресом становится этот отчёт.

- **§1.1.0 — egress-прокси.** Прежний текст: «Egress proxy блокирует домен `liamin-n8n.duckdns.org`. Единственный путь — `n8n:execute_workflow` через MCP.» Наблюдение — вызов вебхука curl/bash из облачной сессии Claude не доходит до инстанса. Та же мысль — `google-drive-docs/SKILL.md:65` («egress-прокси блокирует прямой webhook»).
- **§1.1.3 — `get_execution` без `workflowId`.** Прежний текст: без `workflowId` сервер отдаёт «not found» даже для реального успешного прогона в любом режиме, включая manual; симптом неотличим на глаз от истинной нетрейсируемости R4.
- **§2.1.6 — `availableInMCP`.** Прежний текст: «`availableInMCP` включается только на опубликованном воркфлоу. Перед вызовом незнакомого воркфлоу — проверить флаг через `get_workflow_details`.» Дата и случай не названы.
- **§2.3.7 — миграция credential через `update_workflow`.** Прежний текст: «`update_workflow` не использовать для миграции credential — перетирает `cachedResultName` ссылок на листы Sheets.» Дата и случай не названы; разрешение 4 предполагает, что запрет родился в эпоху записи кодом целиком. Противоположный текст — `google-drive-docs/references/infra.md` 6.2 (г): «мигрировать credential на ВСЕХ узлах одним update_workflow».
- **S0 — замок подтверждения прочтения.** «Фиксированная фраза подтверждением не считается»; довод «её можно произнести, не читая» — из разрешения 12 (`ROOT/inputs/resolutions.md`).
- **§1, способ развёртывания инстанса (прежний SKILL.md строка 92).** Прежний текст таблицы §1: «Версия n8n | не записывается здесь — брать из инстанса в момент использования (self-hosted, Docker Compose)». Факт: инстанс n8n развёрнут самостоятельно (self-hosted) на собственном сервере (по `registry/projects.md` — Hetzner CPX32) через Docker Compose; доступ к базе — `docker exec … psql` (тот же приём в `projects/n8n/STATE.md`, пункт 3 ручных действий, и в R2, R13). В репозитории носителя факта «Docker Compose» нет (поиск `Docker`, `self-hosted` — только прежний Skill); предлагаемый окончательный носитель — канон SERVER (SERVER_INDEX).
