# нет инструмента поиска по неизвестному пути во всём репозитории

Суть: Git Read Lines с pattern (расширение Р-100 журнала `git-migration`, 2026-09-17) и клон закрывают поиск фрагмента, когда путь файла уже известен. Поиска «где в репозитории встречается X» без заранее известного пути не существует ни одним воркфлоу Канала — Git Read Lines принимает ровно один `path` за вызов, Git Grep архивирован (Р-101) и решал ту же однопутевую задачу. Только клон умеет искать по всему дереву (`git fetch && grep -r`), а он есть не в каждой среде: в Claude Project (без bash) вопрос «где ещё в каноне встречается X» сейчас не имеет ответа никаким инструментом.

Идея, поднятая в чате git-migration 2026-09-17 и не проверенная: отдельный воркфлоу на GitHub Code Search REST (`GET /search/code?q=<запрос>+repo:{owner}/{repo}`) — другой API, не Contents API, на котором построен весь нынешний Канал; ответ — список путей с короткими `text_matches` (фрагмент совпадения, не файл целиком), то есть профиль утечки contextData у него не равен профилю архивированного Git Grep и требует отдельного зонда, а не переноса вывода 7.6 по аналогии.

Следующий шаг: не начинать без решения владельца — он попросил обсудить это отдельной сессией (чат 2026-09-17/18), а не строить по умолчанию. При решении «строить»: (1) зонд узла загрузки — вероятно `n8n-nodes-base.httpRequest`, доказать пусто/не пусто `contextData` по образцу карты узлов 7.6, а не предполагать по аналогии с Git Grep; (2) индекс GitHub Code Search покрывает только default-ветку и не индексирует файлы крупнее ~384 КБ — проверить чтением, есть ли такие в `second-brain-canon`, а не полагать, что нет; (3) у search API отдельные, обычно более жёсткие лимиты частоты запросов, чем у Contents API — замерить на пилоте, не выводить теоретически.

Условие снятия: владелец сказал «строить» (задача уходит в наряд на постройку воркфлоу) или «гэп терпим, не строить» (задача закрывается решением, не постройкой) — оба исхода снимают эту позицию лаборатории, разница только в следующем действии.

Ссылки: `second-brain-git` §7.6 (карта узлов Канала, чистые/грязные); Р-100, Р-101 журнала `projects/git-migration/LOG.md` (расширение Git Read Lines и архивация Git Grep закрыли только случай известного пути); чат git-migration 2026-09-17/18.

2026-10-05 — наблюдение (проверка Андрея: вопрос задан новой сессии Cowork без имени летописи — «все ли товары, продаваемые на WB, имеют сопоставленный SKU Ozon и найденную декларацию»).
