# second-brain-git — разрез core/

Часть Skill second-brain-git. Читать: перед разрезом или пересборкой файла core/. Номера пунктов — прежние, общие со SKILL.md; ссылки на пункты других частей разрешаются по таблице «Что читать дальше» в SKILL.md.

6. Разрез core/

6.1. Единица хранения — смысл с названным читателем, не байты. Файл core/ — раздел R-NN канона или его тематическая часть; блок T-NN — минимальная единица, которая не режется никогда.

6.2. Новый материал идёт в файл своей темы. Наличие свободных байт в другом файле основанием для размещения не является.

6.3. Файл core/, переросший разумный для одного раздела размер, делится ПО ТЕМЕ, а не по байтам: граница — там, где меняется предмет, с именем, которое это говорит (R-12-harvest.md, R-12-vychitanie.md), никогда — суффикс без значения. Деление — одним коммитом: новые файлы, удаление старого, правка core/MANIFEST.md и карты разделов; приёмка по 6.8. Транспорт — маршрут 9.4(б): новые файлы собираются скриптом из байтов старого по границам блоков T-NN, а не набираются моделью. Git Commit Files с телами новых файлов в вызове для разреза ЗАПРЕЩЁН: тела — уже существующий текст, класс Р-79 (4.5). Правка Манифеста и карты разделов — текст этой сессии, скрипт вносит её тем же коммитом. Сессия, в которой 9.4(б) неисполним, разрез не начинает — позиция в Очереди с путём файла и датой смерти.

6.4. Если тематического шва нет — файл остаётся целым, каким бы ни был его размер; число байт заносится в карту разделов справочно, позиция в Очередь по одному размеру не заводится. Байтовый разрез ЗАПРЕЩЁН.

6.5. Существующие суффиксные файлы не пересобираются ради правила: отказов адресации через карту не наблюдалось. Условие пересборки — первая содержательная правка соответствующего раздела после снятия заморозки либо отказ разрешения адреса, пришедший сам. Пересборка — тем же коммитом, что правка, по 6.3 и тем же маршрутом 9.4(б).

6.6. Маркеры T-NN остаются в тексте как провенанс блока независимо от файла, в котором блок лежит; карта разделов ведёт «раздел → файлы → блоки».

6.8. Приёмка деления: сумма байт новых файлов равна байтам старого с точностью до заголовков; каждый T-NN старого файла найден ровно в одном новом; Манифест и карта перечитаны, sha названы.
