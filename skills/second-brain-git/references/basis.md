## Устройство Skill

Переложение 2026-10-22 (синтез по харвесту 2026-10-22, отчёт meta/SYNTHESIS_second-brain-git_2026-10-22.md): строки оснований всех файлов Skill вынесены сюда скриптом без изменения текста, в правилах оставлены ярлыки — по разделу «Что такое правило» файла meta/PROTOCOL_knowledge-synthesis.md. Два абзаца шапки SKILL.md, нужные только тому, кто Skill правит, перенесены сюда дословно:

Как устроен этот текст. Он держит правило и число, а не рассказ о том, как правило добывалось. У каждого правила четыре элемента: что делать и когда; почему — механизм одной-двумя фразами; признак, если ситуация неочевидна; основание — число независимых случаев, дата последнего и адрес каждого случая. Сам случай — замеры, номера исполнений n8n, номера нарядов, что подумали сначала и как оказалось — живёт по адресу (запись журнала, позиция Очереди, файл задачи), а не здесь. Шапка — одна строка редакции; что и почему менялось, отвечают история коммитов зеркала skills/second-brain-git/ и журналы из строк основания. Опровергнутая версия, к которой сессия вернётся сама, остаётся одной строкой «Не путать: …». Правка этого Skill готовится по meta/PROTOCOL_knowledge-synthesis.md: урок не дописывается абзацем, а кластер, в который он входит, переписывается заново как правило. Состав Канала, ID воркфлоу и сигнатуры живут в registry/tools.md. Дубль запрещён, поэтому правило выбора инструмента существует ровно в двух местах — таблица 7.6 этого файла для чтения и таблица 8.3 файла references/write.md для записи.

Что где лежит. В этом файле — только то, что нужно любой сессии в момент чтения, какую бы операцию с репозиторием она ни делала. Новый пункт по умолчанию идёт в references/; в этот файл он попадает, только если без него ошибётся сессия, которая references/ не открывала. [основание: GIT-02]
