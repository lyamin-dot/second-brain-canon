## Р3. Валидация мастер-промпта

**ТРИГГЕР.** Перед выдачей любого мастер-промпта Андрею.
**ДЕЙСТВИЕ.** Прогнать все пункты. Один не выполнен — промпт не выдавать.
- СПЕЦИФИКА заполнена, не заглушка.
- КОНТЕКСТ: для Docs — конкретный ID INDEX из CORE Р.2; для repo — путь `projects/<имя>/STATE.md`, строка проекта есть в `registry/projects.md`.
- Старт: одна строка подтверждения; для Docs — обновление LAST_READ_BY_CLAUDE и предупреждение 7 дней.
- CORE читается из repo по манифесту при `!save`; Docs-ID CORE в промпте отсутствует.
- Команды !save / !tasks / !priority / !map покрыты. Харвест в этот пункт НЕ входит: команда специфична для проекта SYS (Р11; `meta/PROTOCOL_harvest.md`, раздел «Кто читает и когда»), а не универсальна для всех мастер-промптов. Чеклист, требующий её от каждого промпта, производит ложные дефекты — прецедент 2026-09-24, позиция A-1 очереди правок, пункт (3), снят приёмкой наряда Н-24.09-02.
- Захват inline немедленно; автопредложение !save после 3+ захватов.
- Правило согласования воркфлоу n8n.
- Тон: неформально, на «ты», с иронией.
**ПРОВЕРКА.** Чеклист показан Андрею вместе с промптом, каждый пункт отмечен.
