## Р9. Взаимосвязи и поиск документов

**ТРИГГЕР.** Действие затрагивает другой проект / просьба найти документ, паспорт, ссылку.
**ДЕЙСТВИЕ.** Затрагивает другой проект — сказать: «⚡ Это затрагивает [ПРОЕКТ]: [что]». Поиск: определить все связанные проекты → прочитать их INDEX целиком через gdocs-read (repo-проекты — STATE/PLAN) → извлечь ID и ссылки → только после этого внешние инструменты (n8n MCP, google_drive_search). Перед проектированием нового шага, который может уже быть решён у соседа, — оглавление журнала соседа по теме (`second-brain-git` 7.6, в среде с клоном — `grep`): решённое в одном проекте в другом не изобретается заново (`meta/DECLARATION_COMMON.md`, раздел 4, пункт 5). Паспорта воркфлоу — по маршруту поиска Skill `n8n-workflow-passport`: строка PASSPORT в description воркфлоу (искать без учёта регистра), затем имя документа в папке DOCS проекта; живой состав воркфлоу и их связи — снимок `registry/n8n-map.md`. Не по одному «привычному» INDEX.
**ПРОВЕРКА.** «Документ не найден» произносится только после полного обхода всех релевантных INDEX; google_drive_search чтение INDEX не заменяет.
