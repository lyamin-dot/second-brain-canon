# second-brain-engineer — команды

Часть Skill second-brain-engineer. Читать: сообщение Андрея начинается с команды из таблицы раздела Р8, целиком. Номера пунктов общие со SKILL.md; ссылки на пункты других частей разрешаются по таблице «Что читать дальше» в SKILL.md.

## Р8. Команды

**ТРИГГЕР.** Сообщение Андрея начинается со слова из таблицы.
**ДЕЙСТВИЕ.** Исполнить по таблице, даже если мастер-промпт проекта команду не перечисляет: регламент команд живёт в этом Skill, промпт его не пересказывает (Р2). Мастер-промпт может переопределить команду для своего проекта — тогда прав промпт. CORE ни одна команда целиком не читает; перед записью вида, названного в таблице «По событию» `core/MANIFEST.md`, читаются файлы её строки. Почему: ни одно правило CORE в исполнении команды чтения не участвует, а чтение CORE ради списка задач оплачивает файлы таблицы «Список» Манифеста впустую.

| Команда | Действие |
|---|---|
| !save | Р7 (references/save.md). |
| !tasks | Открытые задачи текущего проекта по меткам: repo-проект — `STATE.md`; лаборатория — таблица `INDEX.md`; Docs — Зона А INDEX. |
| !priority [high/low/Xh] | Приоритет = метка × вес проекта (БЛОКЕР 4, РЫЧАГ 3, РУТИНА 2, ЗОМБИ 1; веса — `registry/projects.md`). Задача без метки — отдельной строкой «метки нет», не оценивается и метка не угадывается. Без аргумента — текущий проект; со словом «все» — все активные проекты реестра. |
| !inbox | Необработанный Inbox: Google Doc, ID — `registry/documents.md`, строка INBOX; читать gdocs-read; формат записей — `core/R-08.md`. Каждая запись разбирается захватом (Р6) в проект, которому принадлежит. |
| !review | Дайджест по запросу: текущий проект — `STATE.md` (лаборатория — `INDEX.md`) и оглавление журнала; со словом «все» — `STATE.md` всех repo-проектов реестра, `INDEX.md` лабораторий и Зона А Docs-проектов. |
| !status | Блокеры с дедлайнами по всем активным проектам и реестр протоколов (документ SYS_PROTOCOL_REGISTRY, ID — `registry/documents.md`) целиком, таблицей, все строки. Мастер-промпт проекта может задать своё значение (N8N — здоровье инстанса по снимку). |
| !digest [период] | Дайджест CHANGELOG за период, по умолчанию 30 дней; CHANGELOG — Google Doc, ID — `registry/documents.md`, читать gdocs-read. |
| !map | Команда проекта N8N: карта связей проектов и воркфлоу как артефакт (разделы «Связи» в `projects/*/PLAN.md`, строки X и H снимка `registry/n8n-map.md`). В других проектах — ответить, что карта строится в N8N, и не исполнять. |
| харвест | Р11. Команда проекта SYS; в других проектах — ответить, что она запускается в SYS, и не исполнять. |

Естественноязыковой эквивалент !status: любой вопрос «как дела с системой / что с протоколами / какой прогресс» = !status, с полным реестром, без отбора «интересных».

Основание: решения Андрея 2026-09-24 — команды не читают CORE, харвест только в SYS (наряд Н-24.09-02; позиция A-1 `registry/maintenance-queue-archive.md`, пункт 3) и 2026-10-06 — команды исполняются по Skill без перечисления в промпте, `!map` только в N8N (позиции AH-13 и AH-23 `registry/maintenance-queue.md`).
**ПРОВЕРКА.** Ответ на команду назвал прочитанные файлы (Р15); у !priority каждая строка несёт метку и вес или пометку «метки нет».
