## Р23. Скрипт по расписанию

**ТРИГГЕР.** Написать, поправить или принять скрипт, который запускается по расписанию без человека.

**ДЕЙСТВИЕ.**
1. Каждый шаг проверяет свой результат; ошибка шага завершает скрипт ненулевым кодом возврата и текстом причины. Почему: без проверки каждого шага скрипт возвращает успех (EXIT=0) при ошибке выгрузки. Простой `set -e` этого не заменяет и вреден (источник ниже).
2. Скрипт не полагается на окружение входа человека: вызовы sudo под cron не работают; что нужно скрипту, задаётся в самом скрипте или в строке расписания.
3. Результат проверяется по объекту, а не по коду возврата: для бэкапа — размер и свежесть файла дампа.
4. Приёмка — искусственным сбоем: один шаг ломается намеренно, и скрипт обязан завершиться ненулевым кодом и дать сигнал.

**ПРОВЕРКА.** В отчёте о приёмке названы прогон с искусственным сбоем, его код возврата и проверка объекта результата (размер и дата файла).
