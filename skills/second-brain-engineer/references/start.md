# second-brain-engineer — старт сессии

Часть Skill second-brain-engineer. Читать: первое сообщение в Claude Project, мастер-промпт которого несёт блок Второго мозга, — до ответа на это сообщение, целиком. Номера пунктов общие со SKILL.md; ссылки на пункты других частей разрешаются по таблице «Что читать дальше» в SKILL.md.

## Р1. Старт сессии — Правило Феникса

ЗАКОН РАЗДЕЛА. Старт доказывает чтение канона, а не пересказывает его: сессия выводит одну строку с величинами, которые нельзя списать с текста промпта или Skill (blob sha прочитанных файлов), и замолкает. Почему: сессия без памяти начинает работу с того, что прочитала сейчас; строка старта — единственное, по чему Андрей видит, что прочитано и какая версия, а лишний пересказ строку прячет.

**ТРИГГЕР.** Первое сообщение в Claude Project, мастер-промпт которого несёт блок Второго мозга (Р2). Исполняется до ответа на само сообщение: сначала старт, потом ответ. Вне Project (Cowork, Claude Code) автоматически не применяется — см. Р16.
**ДЕЙСТВИЕ.** Тег, носитель и папку проекта называет блок мастер-промпта. При расхождении блока с `registry/projects.md` прав реестр, а расхождение называется в строке старта.

Проект в repo (`projects/<папка>/`):
1. Одним чтением — `meta/PENDING_RULES.md` и `projects/<папка>/STATE.md`. Чем читать — решает `second-brain-git` 7.6 (клон или Git-канал); выбранный путь назвать одной строкой. Строки PENDING_RULES с полем «кто подтвердил: Андрей» действуют как правила Skill (инвариант И-6 `second-brain-git`).
2. Вывести ровно одну строку:
   `Контекст загружен: <ТЕГ> | repo: STATE <sha7>, PENDING_RULES <sha7> | Следующий шаг: <из STATE.md>`
   ТЕГ — имя проекта прописными буквами, как в весах `registry/projects.md` (WB_UE, N8N, WB_REVIEWS); sha7 — первые 7 знаков blob sha прочитанного файла.
3. Молчать, ждать вопроса. Записи на старте нет: у файлов repo нет полей LAST_UPDATED и LAST_READ, свежесть даёт git log (`second-brain-git` 7.4).

Лаборатория в repo (`labs/<папка>/`):
1. Одним чтением — `meta/PENDING_RULES.md` и `labs/<папка>/INDEX.md`. Тела задач на старте не читаются (`second-brain-git` 4б).
2. Вывести ровно одну строку:
   `Контекст загружен: <ТЕГ> | repo: INDEX <sha7>, PENDING_RULES <sha7> | Задач: <число строк таблицы задач>`
3. Молчать, ждать вопроса.

Добавки проекта. Блок мастер-промпта может добавить к старту свои шаги (например, чтение CORE по манифесту) и свой формат строки. Добавка выполняется после шагов выше; если формат строки задан промптом, выводится он, а не строка выше.

Проект в Docs (изолированный контур, Р4 п.0):
1. Прочитать INDEX проекта через gdocs-read — только Зону А, до разделителя ЗОНА Б. `read_file_content` для Docs запрещён (google-drive-docs §0). Зона А читается диапазоном строк (`fromLine`/`toLine`, google-drive-docs §3.5); полнота среза доказывается наличием строки SENTINEL внутри него, а не доверием к числу.
2. Вывести ОДНУ строку: «Контекст загружен: [проект] | [LAST_UPDATED] | Следующий шаг: [шаг]». Если LAST_UPDATED старше 7 дней — добавить «⚠️ Данные не обновлялись 7+ дней».
3. Обновить LAST_READ_BY_CLAUDE через gdocs-replace.
4. Молчать, ждать вопроса.
