## Р16. Работа вне Claude Project и регистрация обязательств

ЗАКОН РАЗДЕЛА. Обязательство существует для системы только записанным в канон: что сессия может исправить — исправляет до конца сессии; что не может — регистрирует позицией, которую прочтёт харвест. Почему: следующая сессия и харвест не читают чатов, поэтому пересказ в чате или в эстафете для них не существует.

**ТРИГГЕР.** Сессия в Cowork / Claude Code / GitHub Actions работает над проектом системы; либо любая сессия вскрыла факт, требующий правки CORE / задачи лаборатории `labs/sys/` / INDEX / Skill / мастер-промпта.
**ДЕЙСТВИЕ.**
- Феникс (Р1) вне Project автоматически не срабатывает. Эстафета (`context-handoff`) — ручной мост: она пишет блок в INDEX проекта (проект в репозитории — `STATE.md`), но автоматического старта вне Claude Project не даёт.
- Запись доступна из любой среды: git-канал и gdocs-* вызываются по HTTP, исполняет сервер n8n. Ограничение — дисциплина, не инструмент.
- Правка, которую сессия МОЖЕТ сделать (CORE, задачи лаборатории `labs/sys/`, INDEX Docs-проектов, файлы repo), — делается до конца сессии, по правильному якорю, с верификацией Р15. Документ SYS_INDEX заморожен: решено 2026-09-23 (Р-109 журнала `projects/git-migration/LOG.md`), заморожен 2026-09-30 (Р-123 того же журнала); его Зона А с 2026-09-14 живёт в `labs/sys/`, и правки туда больше не идут.
- Правка, которую сессия НЕ МОЖЕТ сделать (Skill, мастер-промпт — аккаунтный слой, правит только Андрей), — регистрируется позицией в `registry/maintenance-queue.md` через Git Append File (запасной путь — Git Append; `second-brain-git` 8.3): № | что внести | куда | источник | дата смерти | статус. Позиция без даты смерти не существует. Номер позиции и проверка после записи — `second-brain-git` 8.3, правило (3) под таблицей; однобуквенные префиксы A–Z в файле исчерпаны 2026-09-24, новые позиции берут двухбуквенный префикс. Текст позиции не содержит внутренних переводов строки: они разрывают строку таблицы, колонки «Дата смерти» и «Статус» уезжают на другую физическую строку, и харвест видит позицию без даты смерти. Пересказ в чате и текст эстафеты регистрацией не являются. Очередь читает харвест (Р11).
- Харвест не сканирует внешние чаты: незарегистрированное обязательство для системы не существует.

Основание: эстафета пишет файл — разбор 3 `meta/SKILLS_MAP_resolution_2026-10-19.md`; дата заморозки — разбор 3а-2 там же; разорванная строка очереди — 1 случай, последний 2026-09-24 — отчёт синтеза, правило Р16-4.
