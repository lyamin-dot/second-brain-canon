Правила вида «обязательно X» с явной противоположностью переписаны запретом.
- П — операции нашей системы: вызов Канала, таблица «Чем читать» (7.6), шаблоны, сужение и таблица чистых и грязных воркфлоу, контракты ответов, Git Append File, Git Replace входом fileId, таблица «Чем писать» (8.3), доказательство записи, таблица отказов, push, маршрут доставки 9.4, save по проекту, ротация, разрез core/, новый проект, перенос и его приёмка, заморозка, лаборатория, правка Skill (2.6, шаги 1–4, включая шаг 4 сборки zip), опровержение бюджетов. - М — триггеры описания, строки ЧЧ (реестры, `meta/*`, маршруты в Skills `second-brain-engineer`, `n8n-engineering-manual`, `google-drive-docs`, `naryad`, `context-handoff`, архив).
