Как применялся признак (для проверки шага 4):
- С — любой запрет и любая обязательная проверка перед записью наружу, публикацией, удалением; правило вида «всегда X», у которого есть явная противоположность («никогда не Y»), переписано запретом. «X не помогает / не доказывает» — С.
- Ф-ловушка — вызов движка, узла, SDK или инструмента MCP прошёл без ошибки, а результат неверен (данные потеряны, записаны не туда, отчёт инструмента врёт); и случаи, где ошибка видна, но причина из неё не видна: 429 общей квоты, таймаут на уровне ОС, отказ publish без текста, `status:error` без причины, «not found» из-за пропущенного параметра, падение по памяти. Видимая ошибка с видимой причиной («Can't use .all() here», `$env`, «Column names were updated», 403 «read-only token», «Credentials not found») — О. На шаге 4 в Ф-ловушку перетипированы ошибки, причину которых по тексту не установить: «can't parse entities», «Sheet with ID gid=… not found», `batchUpdate` 400, «invalid syntax», circular, `=[object Object]`, «Multiple matches found», `pairedItemNoInfo`; `completeExpression` — С.
- П — операции нашей системы: вызов воркфлоу из сессии через MCP, порядок записи и сверки, привязка ключей, ротация с запросом Андрею, снятие с публикации с записью в канон, чек-лист перед публикацией, запись во внешний кабинет с режимами, проверка воркфлоу ошибок, двухступенчатая живость.
- П-соглашение — названа зависящая часть: шапка листа (узлы-читатели), горизонтальный лист параметров (воркфлоу-читатель параметров).
- О — устройство n8n, Sheets, Telegram, HTTP и общие приёмы без зависящей части: форма Code-узла, коды JSON шаблонов, арифметика смещения Берлин/Москва, параллельность веток, Header Auth в двух смыслах, перевод литерала в тип credential, состав минимального алерта, TTL-уборка маркеров, писатель «только при изменении».
- И — «Почему», «Не путать» с прежней формулировкой, «Признак», «Основание», [основание: …], даты решений и случаев, «не перепроверено с …», ссылки на журналы и отчёты синтеза как доказательство, редакции и история устройства Skill.
- Номерные перекрёстные ссылки внутри старого текста (*(R1b)*, *(§4.8)*, T4 гейт N) — не забирались: каждая мысль стоит в новом Skill один раз, по месту действия.
