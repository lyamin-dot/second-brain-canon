# n8n-workflow-registry

Указатель: где в каноне лежит каждая деталь инстанса n8n — ID книги, поведение API кабинета, ловушка воркфлоу. Здесь только адрес; деталь — в файле рядом со своими читателями.

## Стоп-правила
- В названном файле не читать больше нужного раздела (Skill `second-brain-git`, «Стоп-правила», подраздел «Чтение»).
- Деталь из файла за объект не принимать: перед решением, которое на ней стоит, сверить с объектом — ID строкой `registry/n8n-map.md` или поиском в Drive, состояние воркфлоу — самим воркфлоу (Skill `second-brain-engineer`, раздел «Р15. Провенанс и верификация — единый стандарт»).
- Пометку `[снимок ДД.ММ]` у строки не читать как «верно сейчас»: она значит «сверено со снимком на эту дату».
- Фиксированную фразу подтверждением прочтения не считать — назвать найденную деталь и её пометку.
- Новую деталь экземпляра в этот Skill не дописывать — в носитель по таблице «Что читать»; носителя нет — вопрос Андрею, а не новый раздел здесь.
- Таблиц по каждому воркфлоу здесь не заводить; строке не хватает адреса — дописать адрес, а не факт.
- Скрипт `processDeclPdfInbox` не запускать (`references/liqui-moly-declarations.md`).

## Как делать
1. Найти строку таблицы «Что читать» по вопросу.
2. Прочитать в названном файле только нужный раздел.
3. Перед решением сверить деталь с объектом (стоп-правила выше).
4. Подтвердить прочтение: назвать найденную деталь и её пометку.
