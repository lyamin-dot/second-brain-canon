# Где лежат детали инстанса

Редакция 2026-10-21.

Этот Skill — указатель, а не справочник. Детали конкретного инстанса — ID книги, поведение API кабинета, ловушка воркфлоу — меняются в любую минуту, и Skill, который их держит, врёт молча: его правят реже, чем меняется объект. Поэтому каждая деталь живёт в файле канона рядом со своими читателями, а здесь только адрес. Основание: решение Андрея 2026-10-20 «Skill — инструкции для всех» (`labs/sys/t-knowledge-synthesis.md`, раздел «Решение Андрея 2026-10-20: Skill — инструкции для всех»); разбор этого Skill по носителям — `meta/SYNTHESIS_n8n-workflow-registry_2026-10-21.md`.

## Как пользоваться

1. Найти строку таблицы по вопросу. В скобках — прежний раздел этого Skill: на него ещё ссылаются другие Skills и файлы канона.
2. Прочитать в названном файле только нужный раздел (`second-brain-git` 7.6).
3. Деталь из файла — запись, а не объект. Перед решением, которое на ней стоит, сверить с объектом: ID — строкой `registry/n8n-map.md` или поиском в Drive; состояние воркфлоу — самим воркфлоу (`second-brain-engineer`, Р15). Пометка `[снимок ДД.ММ]` у перенесённой строки значит «сверено со снимком на эту дату», а не «верно сейчас».
4. Подтверждение прочтения — назвать найденную деталь и её пометку. Фиксированная фраза подтверждением не считается: она доказывает, что файл открыт, а не что в нём что-то нашли.
5. Новая деталь экземпляра сюда не дописывается — в носитель по этой же таблице. Носителя нет — вопрос Андрею, а не новый раздел здесь.
