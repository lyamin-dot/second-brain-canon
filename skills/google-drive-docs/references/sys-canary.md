# google-drive-docs — самопроверка пути записи

Объект: периодическая самопроверка пути записи — воркфлоу по расписанию, который пишет через gdocs-replace v2 в свой тестовый документ. Какой воркфлоу стоит на инстансе — `registry/tools.md`.

- Самопроверка не сверяет наличие подстроки — только уникальное значение своего запуска (точную метку времени): подстрока может остаться от прошлого запуска, и проверка зелёная при несостоявшейся записи.
