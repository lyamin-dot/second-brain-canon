# apps-script-sheets — образцы

Часть Skill apps-script-sheets. Читать: перед постройкой новой витрины или новой книги по сырым данным, целиком, один раз за сессию. Номера параграфов — прежние, общие со SKILL.md; ссылки на параграфы других частей разрешаются по таблице «Что читать дальше» в SKILL.md.

Редакция 2026-10-20.

## 8. ОБРАЗЦЫ

**Новая витрина или новая книга, а также переделка существующей витрины начинаются с рабочего образца, а не с чистого листа.** Почему: в образце уже решены ловушки этого Skill, которые на чистом листе пришлось бы находить заново. Сам Skill не хранит, какая книга сейчас образец, её идентификатор и состояние: образец меняют, замораживают и заменяют, и Skill, который держит имя книги, врёт молча. Где искать (идентификаторы — только в носителе, в Skill не переписываются):

| Что нужно | Где лежит |
| :-- | :-- |
| Рабочая витрина «норма → отклонение → светофор» и её скрипт | канон проекта юнит-экономики Wildberries: `projects/wb-ue/PLAN.md` (книги, документация, конструктор), состояние и заморозки — `projects/wb-ue/STATE.md` и журнал `projects/wb-ue/LOG.md` |
| Документ-конструктор витрины (русская версия для человека и английская для агента) | `projects/wb-ue/PLAN.md`, строка «КОНСТРУКТОР ВИТРИНЫ» |
| Книги по сырым данным и их техдокументация для агента | индекс лаборатории юнит-экономики Ozon: `labs/ozon-ue/INDEX.md` |
| Идентификатор любой книги или документа по имени | `registry/documents.md`; воркфлоу — `registry/n8n-map.md` по имени воркфлоу |
| Опубликован ли и работает ли воркфлоу-читатель образца (курьер Telegram) | `registry/n8n-map.md` и журнал проекта книги — не этот Skill |

Документы Google Docs из этой таблицы читаются через `gdocs-read` (Skill `google-drive-docs`, §0).

**Перед тем как взять образец — проверить, что он жив.** Прочитать в каноне его проекта, не заморожена ли книга и нет ли у неё записанных известных дефектов; замороженная книга годится как история конструкции, но не как образец для новой. Приём из образца, работу которого доказывает внешний исполнитель (например, курьер «книга собирает текст, n8n отправляет»), считается работающим только по состоянию этого исполнителя в его носителе. Основание: 2 случая, последний 2026-10-17 — отчёт синтеза, правило ASS.8.образец.

**Функции, которые даёт сам Skill, берутся из Skill, а не из образца.** `alert_` (SKILL.md §2.2) и `loc_` (SKILL.md §2.1) в старых образцах написаны раньше нынешней редакции Skill; при переносе кода из образца эти функции брать из SKILL.md. Почему: образец не обновляется вместе со Skill, и перенос его копии возвращает уже исправленную ловушку. Основание: 1 случай, последний 2026-09-28 — отчёт синтеза, правило ASS.8.функции.

### Витрина над формулами — что есть в рабочем образце

Зона параметров, бэкап, пошаговый прогон, конвертер локали, `showMap`, `findRefs`, построчные пороги, спарклайны, два графика, лист-руководство (как читать витрину) и ячейки для Telegram (SKILL.md §4, references/design.md §5).

Документ-конструктор витрины отвечает на вопрос «что строить в другой книге»: пять слоёв, разметка каждого листа, шаблон колонок, формула отклонения и правило сигнала, метод подбора порога, порядок сборки, чек-лист переноса на другую площадку.

**Порядок при новой витрине:** §9 — ЗАЧЕМ так устроен сигнал; документ-конструктор — ЧТО именно строить (листы, строки, колонки); §§2–5 — КАК это записать скриптом без ловушек.

### Книга по сырым данным — устройство

- скрипт читает сырой источник и справочники (§4.8, §3.7), сворачивает в памяти, пишет факты значениями, а что-если, распределение расходов и диагнозы — формулами поверх фактов;
- на каждом листе строки 1–8 — инструкция (вопрос, решение, источник, формулы, чего не знает, что-если), строка 10 — шапка, данные с 11-й;
- пустая жёлтая ячейка означает «как в фактах», очистка ячейки возвращает к фактам;
- ручной ввод возвращается по ключу (§4.2), в отчёте — время шагов и сверка денежной колонки с источником (§4.4, §4.5).

При постройке следующей книги такого вида начинать с книг и техдокументации из `labs/ozon-ue/INDEX.md`. Основание: 1 случай, последний 2026-09-28 — отчёт синтеза, правило ASS.8.сырые.
