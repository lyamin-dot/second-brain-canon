## 5. ПРИЁМЫ ОФОРМЛЕНИЯ, КОТОРЫЕ СРАБОТАЛИ

**Цветовая шкала строится построчно, не на весь лист.** Выручка в миллионах и хранение в десятках рублей в одной шкале дают одноцветное хранение. Крайние точки — перцентили 10/50/90, а не минимум и максимум: один выброс (штраф −17 506 ₽ на фоне обычных −100 ₽) иначе съедает всю шкалу.

**Дельты в рублях — цветом текста по знаку через условное форматирование, без заливки.** Дельты в процентах — расходящаяся заливка с фиксированными краями (−20% … 0 … +20%), потому что проценты сравнимы между строками, а рубли нет.

**Расходящаяся заливка — только по колонке с ОДНОЙ единицей.** Если в колонке оказались и проценты, и процентные пункты (§9.3), общая шкала бессмысленна; остаётся окраска текста по знаку.

**Единицы, которые глазом не различить, подписывать форматом ячейки.** `'+0.0" п.п.";-0.0" п.п.";0.0" п.п."'` против `'+0.0%;-0.0%;0.0%'`. «−8,9 п.п.» и «−8,9%» выглядят одинаково и значат разное. Следствие для текстов тревог: в сообщение подставлять величину в ОДНОЙ единице для всех строк — обычно деньги, потому что в сообщении формата ячейки нет.

**Пороги — построчные, со ссылкой на общее значение по умолчанию.** Колонка «порог ₽» и колонка «порог %». Пустой порог означает «этот критерий не применяется» — так строки в других единицах (маржа, штуки) сравниваются только по процентам. Про то, откуда брать сами числа, — §9.5.

**Спарклайн тянется из понедельной витрины через OFFSET по счётчику заполненных недель:**

```
=IFERROR(SPARKLINE(ARRAYFORMULA(ABS(OFFSET(weekly_history!$A$5,0,MAX(1,WEEKS_N-12),1,MIN(13,WEEKS_N)))),
  {"charttype","line";"color","#5B8FF9";"linewidth",2;"empty","ignore"}),"")
```

`ARRAYFORMULA(ABS(...))` обязателен: затраты хранятся отрицательными, и без модуля линия вверх у затрат означала бы их снижение, а у доходов рост — для разных строк одной таблицы разное, читать невозможно. С модулем правило одно: вверх значит «величина выросла».

**Для графиков — отдельный транспонированный блок на дашборде, не транспонирование в опциях графика.** Витрина у Андрея развёрнута неделями по колонкам; блок `TRANSPOSE` внизу листа делает ряды читаемыми и самодокументируемыми, а график ссылается на обычные колонки. Ряды фильтровать по наличию данных за период, иначе ось тянется до конца года пустым хвостом. Ряды с разными базами в стопку не складывать — одни и те же деньги посчитаются дважды.

**Текст тревоги собирается формулами в книге, n8n читает две ячейки.** Вся логика живёт там, где живут данные. Воркфлоу остаётся курьером: пусто — молчит, непусто — отправляет. Именованные диапазоны `TG_ALERT_TEXT` и `TG_WEEKLY_TEXT` делают адрес независимым от разметки. Внутри книги адреса всё равно зашиты, поэтому служебный блок не двигается никогда: если блоку выше нужно место, забирать у соседей сверху.

**`TEXTJOIN` с `ignore_empty = TRUE` выбрасывает задуманные пустые строки-отбивки.** Для сборки сообщения с абзацами нужен `FALSE`; `TRUE` оставить только там, где пустые элементы — это действительно отсутствующие тревоги.

**Пороги сохраняются между прогонами по ИМЕНИ, а не по номеру строки.** Значение принимается, только если в соседней ячейке стоит ожидаемое имя диапазона. Иначе при сдвиге разметки в слот попадёт чужое число с прежнего места.

**Высоту строк текстового листа считать по длине текста, а не задавать числом.** Забытая высота обрезает абзац на середине слова, и это не видно, пока не откроешь лист:

```javascript
function rowHeight_(h, min) {
  var lines = Math.max(
    Math.ceil(String(h[1]).length / 40),
    Math.ceil(String(h[2]).length / 70),
    Math.ceil(String(h[3]).length / 48), 1);
  return Math.max(min, lines * 15 + 12);
}
```

**Порядок колонок на витрине не обязан совпадать с порядком листа-источника.** Зеркалирование задаётся одним списком букв, и перестановка стоит одной строки кода:

```javascript
var MIRROR_COLS = ['A','B','C','E','F','D','G','H'];
```

Менять вместе с ним: шапку блока, числовые форматы в функции оформления, адреса цветовых правил. Сам лист-источник не переставлять — на его колонки ссылаются тексты тревог и плитки, и перестановка там стоит правок в пяти местах вместо одной.
