# apps-script-sheets — приёмы оформления

Часть Skill apps-script-sheets. Читать: перед любой работой с оформлением листа, графиков или текста тревоги, целиком, один раз за сессию. Номера параграфов — прежние, общие со SKILL.md; ссылки на параграфы других частей разрешаются по таблице «Что читать дальше» в SKILL.md.

Редакция 2026-10-20.

## 5. ПРИЁМЫ ОФОРМЛЕНИЯ, КОТОРЫЕ СРАБОТАЛИ

Общий закон раздела: оформление не должно позволить глазу прочитать одно вместо другого — разные масштабы, разные единицы и разные направления «лучше» разводятся явно, а адреса, которые читает кто-то снаружи, не двигаются.

**Цветовая шкала строится построчно, не на весь лист.** Почему: выручка в миллионах и хранение в десятках рублей в одной шкале дают одноцветное хранение. Крайние точки — перцентили 10/50/90, а не минимум и максимум: один выброс (разовый штраф, в десятки раз больше обычного) иначе съедает всю шкалу. Основание: 1 случай, последний 2026-09-15 — отчёт синтеза, правило ASS.5.шкала.

**Дельты в рублях — цветом текста по знаку через условное форматирование, без заливки.** Дельты в процентах — расходящаяся заливка с фиксированными краями (−20% … 0 … +20%). Почему: проценты сравнимы между строками, а рубли нет.

**Расходящаяся заливка — только по колонке с ОДНОЙ единицей.** Если в колонке оказались и проценты, и процентные пункты (§9.3), общая шкала бессмысленна; остаётся окраска текста по знаку.

**Единицы, которые глазом не различить, подписывать форматом ячейки.** `'+0.0" п.п.";-0.0" п.п.";0.0" п.п."'` против `'+0.0%;-0.0%;0.0%'`. Почему: «−8,9 п.п.» и «−8,9%» выглядят одинаково и значат разное. Форматы ещё и не взаимозаменяемы по масштабу: процентный формат умножает хранимое число на 100 при показе (0,089 → «8,9%»), а суффикс «п.п.» только подписывает число как есть (0,089 → «0,1 п.п.»). Поэтому, сменив один формат на другой, проверить величину в ячейке на конкретном числе, а не только имя формата. Признак ошибки: единица в ячейке верна, а величина меньше или больше в сто раз. Следствие для текстов тревог: в сообщение подставлять величину в ОДНОЙ единице для всех строк — обычно деньги, потому что в сообщении формата ячейки нет; формула текста, которая сама умножает на 100 величину, уже хранящуюся в процентных пунктах, даёт ту же ошибку масштаба. Основание: 2 случая, последний 2026-10-14 — отчёт синтеза, правило ASS.5.единицы.

**Пороги — построчные, со ссылкой на общее значение по умолчанию.** Колонка «порог ₽» и колонка «порог %». Пустой порог означает «этот критерий не применяется» — так строки в других единицах (маржа, штуки) сравниваются только по процентам. Про то, откуда брать сами числа, — §9.5; как пороги переживают пересборку — SKILL.md §4.2.

**Спарклайн тянется из понедельной витрины через OFFSET по счётчику заполненных недель** (имя листа истории, адрес первой ячейки ряда и имя счётчика недель — подставить свои):

```
=IFERROR(SPARKLINE(ARRAYFORMULA(ABS(OFFSET(weekly_history!$A$5,0,MAX(1,WEEKS_N-12),1,MIN(13,WEEKS_N)))),
  {"charttype","line";"color","#5B8FF9";"linewidth",2;"empty","ignore"}),"")
```

`ARRAYFORMULA(ABS(...))` обязателен. Почему: затраты хранятся отрицательными, и без модуля линия вверх у затрат означала бы их снижение, а у доходов рост — для разных строк одной таблицы разное, читать невозможно. С модулем правило одно: вверх значит «величина выросла». Формула записывается в локали книги (SKILL.md §2.1).

**Для графиков — отдельный транспонированный блок на дашборде, не транспонирование в опциях графика.** Когда витрина развёрнута периодами по колонкам, блок `TRANSPOSE` внизу листа делает ряды читаемыми и самодокументируемыми, а график ссылается на обычные колонки. Ряды фильтровать по наличию данных за период, иначе ось тянется до конца года пустым хвостом. Ряды с разными базами в стопку не складывать — одни и те же деньги посчитаются дважды.

**Текст тревоги собирается формулами в книге, n8n читает именованные ячейки.** Логика отклонений и тексты сообщений живут там, где живут данные. Воркфлоу остаётся курьером с одной своей проверкой — возрастом книги: метка последнего прогона старше порога или ячейку не прочитать — сообщение «книга не обновлялась» он отправляет сам; иначе пусто — молчит, непусто — отправляет. Почему проверка возраста у курьера: у книги, которая не запустилась, текст тревоги пуст или старый, и курьер «пусто — молчит» промолчал бы ровно тогда, когда книга встала; причина и порог возраста — references/signal.md, §9.9. Не путать: «курьер без своей логики, пусто — молчит» — на деле это пропускает остановку книги. Именованные диапазоны — тексты (например `TG_WEEKLY_TEXT` и `TG_ALERT_TEXT`), метка прогона и последняя дата данных — делают адрес независимым от разметки и читаются одним запросом. Внутри книги адреса всё равно зашиты, поэтому служебный блок не двигается никогда: если блоку выше нужно место, забирать у соседей сверху. Основание: 2 случая, последний 2026-10-16 — отчёт синтеза, правило ASS.5.курьер.

**`TEXTJOIN` с `ignore_empty = TRUE` выбрасывает задуманные пустые строки-отбивки.** Для сборки сообщения с абзацами нужен `FALSE`; `TRUE` оставить только там, где пустые элементы — это действительно отсутствующие тревоги.

**Высоту строк текстового листа считать по длине текста, а не задавать числом.** Почему: забытая высота обрезает абзац на середине слова, и это не видно, пока не откроешь лист:

```javascript
function rowHeight_(h, min) {
  var lines = Math.max(
    Math.ceil(String(h[1]).length / 40),
    Math.ceil(String(h[2]).length / 70),
    Math.ceil(String(h[3]).length / 48), 1);
  return Math.max(min, lines * 15 + 12);
}
```

**Порядок колонок на витрине не обязан совпадать с порядком листа-источника.** Зеркалирование задаётся одним списком букв, и перестановка стоит одной строки кода:

```javascript
var MIRROR_COLS = ['A','B','C','E','F','D','G','H'];
```

Менять вместе с ним: шапку блока, числовые форматы в функции оформления, адреса цветовых правил. Сам лист-источник не переставлять. Почему: на его колонки ссылаются тексты тревог и плитки, и перестановка там стоит правок в пяти местах вместо одной.

Основание остальных приёмов раздела (дельты, расходящаяся заливка, пороги в колонках, спарклайн, блок для графиков, TEXTJOIN, высота строк, порядок колонок): 1 случай, последний 2026-09-16 — отчёт синтеза, правило ASS.5.прочее.
