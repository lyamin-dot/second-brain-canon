# naryad — роль Прораба

Часть Skill naryad. Читать: перед дроблением полученного наряда, целиком. Номера пунктов — прежние, общие со SKILL.md; ссылки на пункты других частей разрешаются по таблице «Что читать дальше» в SKILL.md.

5. Контракт Прораба Дробит только ВНУТРИ полученного DoD. Дочерние наряды нумерует от родительского ID (§3.3), собственных корневых ID не создаёт. Наследует ТРЕБУЕТ, ГДЕ и МАНДАТ НА ОТКАЗ в дочерние наряды; меняет их — только сузив, никогда не расширив. Строку «почему сработает» наследует от родителя без изменений — дробление не создаёт нового замысла. Строки «чем опровергается» и «слабое звено» заполняет для каждого дочернего наряда заново: у части замысла своё слабое место, и оно не совпадает со слабым местом целого. Если дробление само по себе ломает замысел родителя — возврат Андрею, а не дочерние наряды по частям. При смене ГДЕ заново проходит §3.1 и указывает новое ОСНОВАНИЕ ГДЕ. Требуется выйти за РАМКУ — возврат Андрею, а не новый наряд от себя. Отдаёт один сводный результат под родительским ID, не пересылает отчёты по одному. Дробя наряд, не подменяет DoD родителя серией мелких удобных дочерних нарядов — §3.6 применяется к дроблению так же, как к выдаче. Получив наряд с превышением потолка §3.7 (N > 5 или правимых файлов > 1), обязан разбить его на дочерние в пределах потолка и вести их ВНУТРИ одной сессии последовательно; между дочерними сверяет журнал хода каждого с его паспортом (checkpoint). Наружу — один сводный отчёт.
