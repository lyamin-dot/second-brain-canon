ШАГ 0.5 — АДРЕСАЦИЯ (НОВОЕ, решение 1)
Выполняется после ШАГ 0, до физической записи. Отвечает на вопрос «в какой приёмник пишем», если запись инициирована командой !save.
ОБЛАСТЬ ДЕЙСТВИЯ ШАГОВ 0.5 и 0.6 (внесено 2026-10-14, Р-129 журнала `projects/git-migration/LOG.md`). Маршрут этого файла и файла `core/R-06b.md` действует только для записи в документ Google Docs: в INDEX проекта, чей канон — документ INDEX в Google Docs (в `registry/projects.md` такой проект стоит в разделе «Проекты с INDEX в Google Docs» и не стоит в верхних таблицах с носителем repo), в Зону Б, которую пополняет лаборатория или проект из репозитория по своему мастер-промпту, и в INBOX. Проект в репозитории пишет по Skill second-brain-git, пункт 10.3: сдвинулось состояние — STATE.md; принято решение, провалилась попытка, случилась незапланированная отладка — LOG.md по форме пункта 11; изменилось правило проекта — PLAN.md. Лаборатория в репозитории пишет по пункту 4б того же Skill (роли файлов: INDEX.md и файл задачи t-<имя>.md; задача заводится и закрывается вместе со строкой в INDEX.md одним коммитом); находка лаборатории без своей задачи идёт туда, куда велит мастер-промпт лаборатории, а если он не велит — Андрею предлагается завести задачу (Skill second-brain-engineer, `references/save.md`, раздел Р7, пункт 4). Область определяется местом записи, а не носителем проекта: запись лаборатории или проекта из репозитория в документ Google Docs (например, в Зону Б документа INDEX) идёт по маршруту этого файла. Механика записи в репозиторий здесь не повторяется: копия разошлась бы со Skill.
