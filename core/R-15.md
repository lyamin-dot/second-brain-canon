⛔ ПЕРЕД ЛЮБОЙ РАБОТОЙ С ВОРКФЛОУ n8n — ОБЯЗАТЕЛЬНО:








1. Проверить наличие паспорта воркфлоу в WB_UE_INDEX или N8N_INDEX
2. Если паспорт есть — читать ЕГО, НЕ get_workflow_details через MCP
3. Если паспорта нет — читать get_workflow_details, но предупредить об отсутствии документации








ПРИЧИНА: get_workflow_details возвращает сырой JSON на тысячи строк и съедает контекстное окно.
Паспорт содержит готовые факты: ноды, маппинг, matchingColumns, известные баги, ADR.








⛔ ЗАПРЕЩЕНО приступать к работе с воркфлоу без подтверждения:
"Я ознакомлен с технической документацией воркфлоу [название]. Источник: [паспорт / get_workflow_details]."








Это подтверждение Claude обязан выдать явно до любых действий с воркфлоу.
