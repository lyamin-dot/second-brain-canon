При первом обращении к файлу в сессии:
1. Прочитать транспортом его носителя: файл репозитория — по таблице «чем читать» second-brain-git §7.6; документ Google Docs — через gdocs-read (Skill google-drive-docs). Имя конкретного инструмента в этом разделе не пишется: оно устаревает при смене носителя (позиция J-3 очереди).
Шаги 2–5 — только для документа Google Docs. Файл репозитория прочитан в текущей версии main по построению, его версию называет blob sha из ответа; полей LAST_* у него нет (second-brain-git 7.4).
2. Показать: [файл] — данные на [LAST_UPDATED]
3. Если > 48 часов → предупредить
4. Если LAST_UPDATED > LAST_READ_BY_CLAUDE → предупредить об изменениях
5. Обновить LAST_READ_BY_CLAUDE








Никогда не использовать данные из предыдущей сессии.
